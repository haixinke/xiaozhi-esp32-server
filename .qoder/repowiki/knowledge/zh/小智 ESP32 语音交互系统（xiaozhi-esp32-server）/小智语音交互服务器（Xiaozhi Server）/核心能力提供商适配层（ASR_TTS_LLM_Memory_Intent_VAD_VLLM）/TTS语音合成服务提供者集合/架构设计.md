模块以抽象基类 `base.TTSProviderBase` 为核心，定义统一的 `text_to_speak` 抽象方法以及文本分段、队列消费、Opus编码、音频播放线程等通用逻辑；每个厂商或协议在独立文件中实现一个同名 `TTSProvider` 类继承该基类。
- `dto/dto.py` 定义跨层数据契约：`SentenceType`（FIRST/MIDDLE/LAST）、`ContentType`（TEXT/FILE/ACTION）、`InterfaceType`（DUAL_STREAM/SINGLE_STREAM/NON_STREAM）和 `TTSMessageDTO`。
- `default.py` 提供默认占位实现，`index_stream.py` 提供单流式默认实现（24kHz PCM→Opus），其余文件（aliyun、openai、custom、doubao、edge、fishspeech、huoshan_double_stream、minimax_httpstream、paddle_speech、siliconflow、tencent、xunfei_stream、cozecn、gpt_sovits_v2/v3 等）各自对接特定厂商API。
- 依赖方向单向向下：具体实现 → `base.TTSProviderBase` → `core.utils`（opus_encoder、textUtils、audio工具）→ 上层连接对象 `conn`（sample_rate、stop_event、loop 等）。
