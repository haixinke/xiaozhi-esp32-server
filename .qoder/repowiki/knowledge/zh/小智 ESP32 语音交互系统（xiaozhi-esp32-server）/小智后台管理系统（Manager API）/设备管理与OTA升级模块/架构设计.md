模块采用标准的 Controller-Service-Dao-Entity 分层结构：
- controller 层：DeviceController 处理设备绑定/解绑/更新/工具调用等管理接口，OTAController 暴露设备端 OTA 检查与激活接口，OTAMagController 负责固件上传管理。
- service 层：DeviceServiceImpl 继承 BaseServiceImpl<DeviceDao, DeviceEntity>，封装设备激活、在线状态查询、工具调用转发、WebSocket/MQTT 配置生成等核心逻辑；OtaService 抽象 OTA 固件管理；DeviceAddressBookService 管理设备通讯录权限。
- dao 层：MyBatis-Plus 的 Mapper 接口（DeviceDao、OtaDao、DeviceAddressBookDao）。
- entity 层：DeviceEntity、OtaEntity、DeviceAddressBookEntity 对应 ai_device、ai_ota、ai_device_address_book 表，使用 MyBatis-Plus 注解映射。
- dto/vo 层：请求 DTO 与响应 VO 分离，通过 ConvertUtils/BeanUtils 转换。
- 对外通信：通过 MqttGatewayAuthorization 以 SHA256 日令牌鉴权 POST 到 MQTT Gateway，再转发 JSON-RPC 到设备；WebSocket 认证通过 HMAC-SHA256 签名 token 实现。
- 依赖方向：controller → service → (dao + Redis + SysParamsService + SecurityUser)，service 间通过接口解耦，无循环依赖。
