- 每个 ASR 提供商独立一个文件，类名统一为 `ASRProvider(ASRProviderBase)`，并在 `__init__` 中设置 `self.interface_type = InterfaceType.XXX`
- 所有 provider 必须实现 `speech_to_text(self, opus_data: List[bytes], session_id: str, artifacts=None) -> Tuple[Optional[str], Optional[str]]`，返回 (文本, 文件路径)
- 需要文件的 provider 通过重写 `requires_file() -> bool` 声明，优先使用临时文件的通过 `prefers_temp_file()` 声明
- 日志输出统一使用 `TAG = __name__` + `logger = setup_logging()` + `logger.bind(tag=TAG).info/error/debug(...)` 模式
- 配置项通过 `config.get(...)` 读取，输出目录统一通过 `os.makedirs(self.output_dir, exist_ok=True)` 确保存在
- 异常处理统一捕获后记录错误日志并返回空字符串或 None，保证上层调用稳定
