- 每个插件文件顶部定义一个 OpenAI function 风格的描述字典（包含 name/description/parameters），并通过 `@register_function` 装饰器将函数注册到全局注册表。
- 插件函数统一返回 `ActionResponse(action=..., result=..., response=...)` 结构体，根据 `ToolType` 选择 `REQLLM`、`RESPONSE`、`NONE`、`ERROR` 等动作类型。
- 需要访问连接上下文的插件函数以 `conn: ConnectionHandler` 作为第一个参数，并通过 `TYPE_CHECKING` 避免循环导入。
- 每个插件文件使用 `TAG = __name__` 配合 `logger.bind(tag=TAG)` 进行结构化日志记录。
- 外部 HTTP 请求统一使用 `httpx.AsyncClient` 并设置超时，异常捕获后返回 `ActionResponse(Action.ERROR, ...)` 或友好错误消息。
