- 控制器方法统一返回 `Result<T>` 包装，并使用 `@Valid` 校验 DTO 参数。
- 实体类通过 MyBatis-Plus 注解（`@TableName`、`@TableId`、`@TableField(fill=...)`）映射数据库字段，审计字段 `createdBy`/`updatedBy`/`createdAt`/`updatedAt` 由框架自动填充。
- 业务异常统一抛出 `RenException(ErrorCode.XXX)`，如 `COMPANION_NOT_FOUND`、`NO_PERMISSION`、`COMPANION_ALREADY_EXISTS`。
- 纯算法逻辑（亲密度计算、心情权重、经期周期、券规则）放在 `util` 包中以静态方法形式暴露，不依赖 Spring 容器以便独立测试。
- 跨模块调用通过构造函数注入服务（`@AllArgsConstructor` + `private final` 字段），避免字段级 `@Autowired`。
