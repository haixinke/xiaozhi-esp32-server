模块以 `base.py` 中的抽象基类 `LLMProviderBase` 为核心契约，定义 `response(session_id, dialogue)` 流式生成器与 `response_with_functions(session_id, dialogue, functions)` 函数调用接口，并提供 `response_no_stream` 默认实现。每个 LLM 厂商在独立子包（如 `openai/`、`gemini/`、`dify/`、`AliBL/`、`coze/`、`fastgpt/`、`ollama/`、`xinference/`、`homeassistant/`）中实现同名 `LLMProvider` 类并继承该基类，从而保持一致的调用约定。`system_prompt.py` 提供工具调用的系统提示模板，被 Dify 等需要手动拼接 tool prompt 的提供商复用。依赖方向单向：各具体 Provider → `base.LLMProviderBase` + `core.utils.util.check_model_key` + `config.logger.setup_logging`，彼此之间无横向依赖。
