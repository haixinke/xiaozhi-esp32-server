模块遵循微信小程序标准工程结构：`miniprogram/` 为小程序根目录，`app.js` 作为应用入口统一处理登录态（`ensureLogin`/`silentLogin`）、全局 `globalData` 字段注入以及未绑定用户到 welcome 页的重定向；`app.json` 声明 tabBar（蛋宝宝/我的双 Tab）与自定义导航栏。分层清晰：
- `pages/` 按业务域划分（home、chat、album、profile、settings、welcome 等），每个 Page 由 js/json/wxml/wxss 四件套组成，部分含 `.test.js`。
- `components/` 为可复用 UI 组件（button、card、nav-bar、egg-avatar、pet-avatar、signal-bars、mood-badge、list-row、switch-row、collapse-item），均按 Component({ properties, data, methods }) 模式定义。
- `utils/` 封装领域能力：`request.js` 统一 HTTP 请求（自动 Bearer 鉴权、401 静默刷新、错误信封解析）、`auth.js` 管理 wx.setStorageSync 中的会话、`websocket.js` 实现带心跳/指数退避重连的 WebSocketManager 类、`pet-store.js` 作为本地 pet/user 数据层并调用 `pet-api.js` 与后端交互、`wechat-api.js` 封装微信授权接口。
- `config/api.js` 集中配置 `API_BASE_URL`（默认指向本地开发 `192.168.4.128:8002/xiaozhi`）。
- `libs/opus/` 集成 WebAssembly Opus 解码器用于音频播放。
依赖方向单向：Page → utils/components/config，utils 之间仅通过明确模块引用，无循环依赖。顶层 `scripts/verify-project.js` 在构建前校验项目结构完整性与 PRD 约束。
