模块按 Spring MVC 标准分层组织，分为 voiceclone（声音克隆）和 timbre（音色）两个子包，每个子包均包含 controller/dao/dto/entity/service 五个目录：
- controller 层通过 `@RestController` + `@RequestMapping` 暴露 REST 接口，使用 Shiro 的 `@RequiresPermissions` 做权限控制，统一返回 `Result<T>` 包装。
- service 接口继承通用 `BaseService<Entity>`，实现类位于 impl 子包，封装业务逻辑（如 VoiceCloneServiceImpl 中的音频上传、Redis 临时 ID 映射、调用 ItemService 消耗配额、触发火山引擎 cloneAudio 训练）。
- dao 层由 MyBatis-Plus 生成，entity 使用 `@TableName`、`@TableId`、`@TableField(fill=...)` 注解映射数据库表（ai_voice_clone、ai_tts_voice），并配合 Swagger `@Schema` 描述字段。
- dto/vo 用于请求参数校验与响应数据隔离，VO 仅用于展示（如 TimbreDetailsVO）。
- 依赖方向单向向下：controller → service → dao，voiceclone 还依赖外部模块 item（ItemService 消费 quota）、model（ModelConfigService 获取 TTS 平台列表）以及 RedisUtils 做临时映射缓存。
