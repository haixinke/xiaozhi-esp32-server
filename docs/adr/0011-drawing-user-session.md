# 0011. 一起画以用户为局次与额度归属，完成时按当前配置结算

一起画要求开局时当前选中的宠物已破壳，但局次、每日成功开局次数和每日首次完成奖励均归用户。活动与小纸条共享额度，切换宠物或入口不增加机会；听你说同样由游戏管理的 `daily_limit` 控制用户每日局次，0 表示不限。

局次仅保存归属用户、请求幂等键、参考图、开局计次日与时间、完成时间和奖励状态，不保存宠物、定价快照或钱包事实。次数归开局日，奖励资格归成功完成日；开局不扣费、不发奖，也不承诺奖励星数。扣费和发奖均在 complete 接口按当时有效的游戏配置执行，运营修改配置会影响尚未完成的局次。完成仅校验局次归属，不再次要求开局宠物仍存在。

局次与完成状态由绘画业务维护，星星金额与余额以每日奖励记录、钱包账户及流水为准，遵循 ADR 0008 与 0009；完成状态与结算同事务提交，同一局重试不重复奖扣。重试已完成局次不再读取新配置，奖励金额按完成日原奖励事实回放，余额实时查询。绘画及完成门槛校验全部在小程序本地进行，完成时只提交局次 ID；画作、坐标、绘画时间和其他过程数据不上传或入库，也不因展示彩色临摹素材而授予道具库存。
