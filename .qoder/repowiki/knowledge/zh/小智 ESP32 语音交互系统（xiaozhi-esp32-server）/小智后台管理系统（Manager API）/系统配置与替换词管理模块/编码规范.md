- Controller 统一使用 Lombok `@AllArgsConstructor` 构造注入 Service，并通过 `xiaozhi.common.utils.Result` 包装返回值。
- DTO 入参统一使用 `@Valid` 配合 `ValidatorUtils.validateEntity(dto)` 进行参数校验。
- 实体类通过 MyBatis-Plus 注解（`@Data`、`@TableName`、`@TableId`、`@Schema`）声明表映射与 Swagger 文档。
- DAO 接口继承 `BaseDao<Entity>` 并标注 `@Mapper`，复用通用 CRUD 方法。
- 配置与配额相关数据通过 `RedisUtils` 与 `RedisKeys` 常量键进行缓存与原子操作。
- 需要权限控制的接口统一使用 Shiro `@RequiresPermissions("sys:role:normal")` 注解声明访问权限。
