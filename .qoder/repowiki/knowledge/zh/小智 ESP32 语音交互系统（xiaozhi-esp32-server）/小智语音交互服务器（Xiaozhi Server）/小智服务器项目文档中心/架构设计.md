该模块为纯文档目录，按功能主题划分为多个子目录：`powermem/` 记录 PowerMem 记忆系统的算法原理、元数据字段、SQL 生成与处理流程；`device/` 描述 ESP32 设备的接入、认证与工作流程；`websocket/` 说明 WebSocket 音频流与 ASR 处理；`llm/` 涵盖 LLM 工具调用、提示词架构与工具函数注册机制；`guides/` 提供用户入门与配置指南；`architecture/` 保存系统架构蓝图与设计文档；`issues/` 记录关键问题的根因分析；`refactor/` 存放重构设计文档。根目录包含总索引 `README.md` 以及缓存实现、成本估算、生产就绪评估等跨主题文档。各子目录之间无代码依赖，仅通过交叉引用关联。
