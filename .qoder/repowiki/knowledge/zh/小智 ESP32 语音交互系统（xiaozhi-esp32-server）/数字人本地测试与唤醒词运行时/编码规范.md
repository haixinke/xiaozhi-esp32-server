- 插件通过 `PluginManager.register()` 注册并按 `priority` 属性排序，统一实现 `setup/start/stop/shutdown` 四阶段生命周期方法。
- 前后端通信采用统一的 JSON 消息格式 `{type, requestId, success, payload, error?}`，由 `WakewordEventBridge.build_message` 生成，事件类型以 `_result` 后缀区分请求响应。
- 异步事件通过 `queue.Queue` 配合线程锁在 `WakewordEventBridge` 中广播给所有已连接客户端，满队列时自动清理过期客户端。
- 前端模块使用 ES Module import 语法，并通过 URL 参数 `?v=0205` 进行版本缓存控制。
- 配置与日志通过 `load_config(runtime_root)` 和 `setup_logging(log_file, log_level)` 集中初始化，运行时重启时重新加载配置并重建应用实例。
