- 所有 HTTP Handler 继承自 `BaseHandler`，并在 `__init__` 中通过 `super().__init__(config)` 复用配置与日志器。
- 每个路由方法（`handle_get`/`handle_post`/`handle_download`）都包裹 try/except/finally，在 finally 中统一调用 `_add_cors_headers(response)` 添加跨域响应头。
- 错误处理采用统一的 JSON 结构 `{"success": False, "message": "..."}`，并通过 `web.Response(content_type="application/json")` 返回。
- 请求参数优先从 HTTP Header 读取（如 `device-id`、`client-id`、`device-model` 等），失败后回退到请求体 JSON 字段。
- 敏感操作（如 MQTT 密码生成、Token 验证）通过 `core.auth.AuthManager` / `core.utils.auth.AuthToken` 封装，避免在 Handler 内直接实现加密逻辑。
