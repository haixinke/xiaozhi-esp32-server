## 软件功能与技术特点（填表参考文案）

> 以下为草稿，可按系统字数限制删减。

爱予慧蛋宝宝AI宠物小程序软件是上海爱予慧科技有限责任公司独立开发的 AI 宠物养成微信小程序，面向移动端用户提供蛋宝宝孵化、AI 对话、NFC 领取、收藏卡与涂鸦相册等陪伴式养成体验，与 ESP32 智能语音终端及智控台管理平台形成完整产品生态。小程序采用微信原生框架（WXML/WXSS/JavaScript）开发，通过 HTTPS 接入后端 RESTful API 获取业务数据，本地维护宠物状态机与场景渲染逻辑，支持弱网环境下的兜底展示。

主要功能模块：

1. 孵化养成：孵化引导、宠物取名、心愿问卷、分龄课程互动，驱动蛋宝宝从蛋形态到破壳后的完整成长链路；
2. NFC 领取与设备绑定：触碰实体 NFC 标签完成宠物领养与资产绑定，引导用户绑定 ESP32 智能语音终端建立语音交互能力；
3. 互动内容：收藏卡图集浏览、涂鸦相册作品回顾、AI 文字与语音对话、聊天参数个性化设置；
4. 个人中心：宠物概况汇总、用户资料编辑、账号绑定管理、系统通用设置；
5. 年龄与邀请：分龄内容推荐、专属邀请码分享与奖励；
6. 帮助与合规：用户反馈（含受理编号追溯）、帮助指引、账号注销、隐私政策与用户条款。

技术特点：基于微信原生框架的轻量前端架构；本地宠物状态机与场景渲染保证弱网可用性；定时故事状态切换与背景轮播营造陪伴感；NFC 标签触碰激活实现实体资产与数字宠物的一一对应；分龄课程推荐保障内容适龄性。
