手机 ↔ 板端 BLE / 手机 ↔ 后端 HTTPS

      术语速查 · 找入口、拆消息、接收回执
      服务、特征、UUID
      服务是一组功能，特征是具体的读写入口。UUID 是入口编号。FFF0 是服务，FFF2 接请求，FFF1 回应答。FFF0 的全写为 0000FFF0-0000-1000-8000-00805F9B34FB。
      双向分包
      手机发长指令要拆包，板端回长应答也要拆包。收件方按原顺序拼回完整一行。
      LF、CRLF
      LF 是协议的一行结束标记，字节为 0A。CRLF 是 0D 0A 两个字节，协议接收端也能识别。
      Write、Write Without Response
      手机向 FFF2 写入。前者有蓝牙层写入回执，后者没有这一层回执。业务结果由板端的 !OK 或 !ERR 告诉小程序。
      Notify、Indicate
      板端通过 FFF1 把数据送回，手机要先订阅。Indicate 有手机蓝牙栈的接收确认，Notify 无这一步确认。
      ATT MTU
      一个 ATT 消息最多可有多少字节。默认 23 字节，这里的常用写和应答方式扣去 3 字节开销后，可带 20 字节数据。
