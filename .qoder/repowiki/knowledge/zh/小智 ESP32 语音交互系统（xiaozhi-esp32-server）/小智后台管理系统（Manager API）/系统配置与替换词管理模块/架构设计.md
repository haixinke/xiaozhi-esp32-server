模块由两个并列的子包组成：
- `config`：面向设备端与管理控制台的配置聚合层。`ConfigController` 暴露 `/config` 下的 server-base、agent-models、correct-words、chat-quota/check 四个接口；`ConfigService` 定义配置获取、模型装配、替换词拼装与配额检查的抽象；`ConfigServiceImpl` 通过组合 `SysParamsService`、`DeviceService`、`ModelConfigService`、`AgentService`、`TimbreService`、`VoiceCloneService`、`SubscriptionService`、`CorrectWordFileService` 等多个领域服务，将系统参数（按点号分层）与各类模型配置动态拼装为 JSON 返回，并使用 Redis 缓存配置键 `RedisKeys.getServerConfigKey()`；`SystemInitConfig` 在应用启动时依赖 Liquibase 完成后初始化 Redis 版本、系统密钥并预热配置缓存。
- `correctword`：替换词文件 CRUD 管理。`CorrectWordController` 提供 `/correct-word/file` 的创建、修改、分页列表、下拉选择、下载、删除与批量删除接口，使用 Shiro `@RequiresPermissions("sys:role:normal")` 做权限控制；`CorrectWordFileService` 及其实现封装文件与词条的持久化逻辑；`CorrectWordFileEntity`/`CorrectWordItemEntity` 通过 MyBatis-Plus 注解映射到 `ai_agent_correct_word_file` 表，DAO 继承 `BaseDao` 获得通用 CRUD。
依赖方向：Controller → Service → (DAO / 其他领域 Service)，config 模块通过注入 `CorrectWordFileService` 获取设备对应的替换词列表，形成 config 对 correctword 的单向依赖。
