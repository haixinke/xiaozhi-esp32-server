- 每个业务模块遵循 controller/dao/dto/entity/service(impl)/vo 的标准分层结构，Mapper XML 统一放在 resources/mapper/{module}/ 目录下
- 实体类继承 BaseEntity，Service 继承 BaseService/CrudServiceImpl，DAO 继承 BaseDao，复用通用 CRUD 逻辑
- 统一通过 Result<T> 包装响应体，异常使用 RenException + RenExceptionHandler 全局处理并返回 ErrorCode
- 参数校验采用 Hibernate Validator 分组（AddGroup/UpdateGroup/DefaultGroup），DTO 字段使用 @Validated 注解
- 数据库变更通过 Liquibase 增量脚本管理，文件名格式为 yyyyMMddHHmm.sql，由 db.changelog-master.yaml 统一注册
