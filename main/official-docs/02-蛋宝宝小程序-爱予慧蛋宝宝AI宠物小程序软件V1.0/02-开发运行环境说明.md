# 爱予慧蛋宝宝AI宠物小程序软件 V1.0 — 开发运行环境说明

## 开发的硬件环境

MacBook Pro（Mac17,2），Apple M5 芯片，32GB 内存。

## 运行的硬件环境

支持微信客户端的智能手机（iOS / Android），4GB 内存以上；NFC 领取功能需手机具备 NFC 近场通信能力。

## 开发该软件的操作系统

macOS 26。

## 软件开发环境 / 开发工具

- 微信开发者工具（小程序开发、调试与预览）；
- Git（版本管理）。

## 该软件的运行平台 / 操作系统

微信客户端（iOS / Android），微信小程序运行环境，依赖微信小程序基础库 2.x 及以上版本。

## 软件运行支撑环境 / 支持软件

- 微信客户端（最新稳定版）；
- 微信小程序基础库 2.x+；
- 配套后端：爱予慧AI智能体管理服务后端（RESTful API，HTTPS 接入）。

## 编程语言

JavaScript（微信原生小程序框架 WXML / WXSS）。

## 源程序量

约 19000 行（取蛋宝宝小程序 JS / WXML / WXSS / JSON 源代码实测约 1.9 万行，含注释）。

## 开发目的

为 AI 语音陪伴硬件产品提供移动端用户入口，让用户通过微信小程序完成蛋宝宝宠物的孵化养成、AI 对话互动、NFC 实体资产领取与设备绑定，构建"实体硬件 + 数字宠物 + 移动应用"的完整陪伴式养成体验。

## 面向领域 / 行业

人工智能物联网（AIoT）、AI 语音陪伴智能硬件、情感陪伴科技行业的移动应用领域。

## 软件的主要功能

1. 孵化养成：孵化引导、宠物取名、心愿问卷、分龄课程互动，驱动蛋宝宝从蛋形态到破壳后的完整成长链路；
2. NFC 领取与设备绑定：触碰实体 NFC 标签完成宠物领养与资产绑定，引导用户绑定 ESP32 智能语音终端建立语音交互能力；
3. 互动内容：收藏卡图集浏览、涂鸦相册作品回顾、AI 文字与语音对话、聊天参数个性化设置；
4. 个人中心：宠物概况汇总、用户资料编辑、账号绑定管理、系统通用设置；
5. 年龄与邀请：分龄内容推荐、专属邀请码分享与奖励；
6. 帮助与合规：用户反馈（含受理编号追溯）、帮助指引、账号注销、隐私政策与用户条款。

## 软件的技术特点

- 基于微信原生框架的轻量前端架构，无第三方运行时依赖；
- 本地宠物状态机与场景渲染逻辑保证弱网环境下的兜底展示；
- 定时故事状态切换与背景轮播营造陪伴感；
- NFC 标签触碰激活实现实体资产与数字宠物的一一对应；
- 分龄课程推荐机制保障内容适龄性。
