模块采用标准的 Controller → Service → Dao 三层结构：
- controller/ 下每个实体对应一个 Spring MVC @RestController，统一以 /admin 或 /admin/dict/* 为路径前缀，使用 @RequiresPermissions("sys:role:superAdmin") 做接口级权限校验，并通过 io.swagger.v3 注解生成 OpenAPI 文档。
- service/ 定义接口并继承 xiaozhi.common.service.BaseService<S>，impl/ 中实现类继承 BaseServiceImpl<S, T>，复用通用分页、CRUD 能力；业务方法通过 @Transactional(rollbackFor = Exception.class) 声明事务。
- dao/ 中的 Mapper 接口继承 xiaozhi.common.dao.BaseDao<T>，配合 @Mapper 注解由 MyBatis-Plus 自动注入，无需手写 SQL。
- entity/ 使用 Lombok + MyBatis-Plus 的 @TableName/@TableField(fill=...) 映射 sys_user、sys_dict_type、sys_dict_data、sys_params 等表。
- dto/ 用于入参校验，vo/ 用于出参封装，二者通过 ConvertUtils.sourceToTarget 与实体互转。
- enums/ 存放 SuperAdminEnum、ServerActionEnum 等常量枚举。
- redis/SysParamsRedis 负责参数缓存读写。
- utils/ 提供 WebSocketClientManager 等工具类，独立于业务层。
依赖方向严格单向：controller → service → (dao + 其他模块如 DeviceService/AgentService)，不反向依赖。
