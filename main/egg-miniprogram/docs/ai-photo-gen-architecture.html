双端审核: 用户上传照片 + AI 生成结果图, 均接入微信内容安全 mediaCheckAsync 2.0 · 审核通过才进入下一环节

双端内容安全审核 (核心)

  • • 第一道: 用户上传照片, 先审核后生成, 驳回直接终止
  • • 第二道: AI 生成结果图, 先审核后下发, 驳回用户不可见
  • • 均接入微信内容安全 mediaCheckAsync 2.0 异步图片审核
  • • 仅 suggest=pass 视为通过, review/risky 一律保守驳回
  • • openid + trace_id 全程关联, 审核记录可溯源
  • • 结果 URL 仅在审核通过 (SUCCEEDED) 后下发小程序

审核流程 (①-⑧)

  • ① 小程序上传照片 (Bearer Token 认证)
  • ② 照片写入 OSS ai-gen/ (白名单前缀校验)
  • ③ 后端提交照片审核 (附 openid, 返回 trace_id)
  • ④ 微信异步回调审核结论 (验签 SHA1 + AES 解密)
  • ⑤ 通过 → Seedream 生成 (照片+IP参考图+预置文案)
  • ⑥ 结果图写入 OSS
  • ⑦ 提交结果图二次审核, 回调机制同 ④
  • ⑧ 通过 → 小程序轮询获得结果图, 可保存/分享

认证与回调可信

  • • wx.login → /wechat/login 换取 Token, 全程 Bearer 认证
  • • Shiro OAuth2 过滤器 + 接口级权限 sys:role:normal
  • • 回调端点匿名开放, 安全依赖 SHA1 验签 + AES 安全模式
  • • XML 解析关闭 DTD/外部实体, 防 XXE 攻击
  • • token / openid / wx.login code 不落日志、不入库

风险控制与配额

  • • 每日成功上限 3 次, 审核驳回/生成失败不计配额
  • • 任务状态机: PENDING→RUNNING→REVIEWING→SUCCEEDED/FAILED
  • • 回调条件更新保证幂等, 微信重推不影响终态
  • • 中间态超 24h 定时任务批量置 FAILED 兜底
  • • OSS PublicRead 仅用于微信审核拉取, 路径含用户/任务隔离
