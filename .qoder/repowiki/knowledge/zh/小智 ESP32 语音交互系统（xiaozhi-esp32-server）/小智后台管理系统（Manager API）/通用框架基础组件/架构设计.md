本模块是 manager-api 的公共基础层，按职责划分为多个子包：
- entity/dao/service 构成 MyBatis-Plus 三层骨架：BaseEntity 定义 id/creator/createDate 等公共字段并通过 FieldMetaObjectHandler 自动填充；BaseDao<T> 继承 BaseMapper<T>；BaseService<T> 与 BaseServiceImpl<M,T> 封装增删改查及批量操作，CrudService<T,D> 进一步抽象 DTO 分页查询与 CRUD。
- config/ 下集中声明 Spring Bean：MybatisPlusConfig 注册数据权限、分页、乐观锁、防全表更新拦截器；RestTemplateConfig、SwaggerConfig、AliyunOssConfig、AsyncConfig、RedisConfig 分别配置 HTTP、文档、OSS、异步线程池与 Redis。
- exception/ 通过 RenException + ErrorCode + RenExceptionHandler(@RestControllerAdvice) 统一返回 Result<T> 格式的错误响应。
- interceptor/ 实现 MyBatis InnerInterceptor（DataFilterInterceptor）基于 JSQLParser 动态拼接 WHERE 条件，配合 DataScope 注解完成数据权限过滤。
- redis/ 封装 RedisUtils 工具类，默认过期时间策略 + Lua 脚本原子操作。
- xss/ 提供 XssFilter、XssHttpServletRequestWrapper、SqlFilter 等请求清洗能力。
- validator/group/ 使用 JSR-303 Group 接口（AddGroup/UpdateGroup/DefaultGroup）区分校验场景。
- utils/ 聚合 Result、JsonUtils、DateUtils、AES/SM2 加密、TreeUtils、HttpContextUtils 等通用工具。
依赖方向：业务模块依赖本模块，本模块不反向依赖任何业务包，仅通过 SecurityUser 从 security 模块获取当前用户上下文。
