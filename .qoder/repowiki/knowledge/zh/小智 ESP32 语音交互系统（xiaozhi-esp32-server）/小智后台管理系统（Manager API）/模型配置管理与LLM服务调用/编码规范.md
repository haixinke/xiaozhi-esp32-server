- Controller统一使用@AllArgsConstructor构造注入、@RequestMapping路径前缀、@Tag描述分组、@Operation标注接口说明，并通过@RequiresPermissions进行权限校验
- 实体类使用Lombok @Data、MyBatis-Plus @TableName/@TableField注解，JSON字段通过JacksonTypeHandler自动序列化
- DTO与Entity之间通过ConvertUtils.sourceToTarget进行转换，避免手动赋值
- 所有对外API返回值包装在Result<T>中，分页数据使用PageData<T>
- LLM服务实现类内部维护默认提示词模板常量（DEFAULT_SUMMARY_PROMPT、DEFAULT_TITLE_PROMPT），通过字符串替换注入上下文变量
- 对第三方LLM调用的异常统一捕获并返回友好错误消息，失败时记录log.error而非抛出异常
