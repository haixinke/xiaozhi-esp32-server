# 爱予慧AI智能体管理服务后端 V1.0 — 开发运行环境说明

## 开发的硬件环境

MacBook Pro（Mac17,2），Apple M5 芯片，32GB 内存。

## 运行的硬件环境

Linux 服务器（如 CentOS 7 / Ubuntu 20.04），4 核 CPU / 8GB 内存以上，支持 Docker 部署。

## 开发该软件的操作系统

macOS 26。

## 软件开发环境 / 开发工具

- IntelliJ IDEA（Java 开发）；
- JDK 21；
- Maven（依赖管理与构建）；
- Liquibase（数据库版本化迁移）；
- Git（版本管理）。

## 该软件的运行平台 / 操作系统

Linux 服务器操作系统（如 CentOS 7 / Ubuntu 20.04），支持 Docker 容器化部署。

## 软件运行支撑环境 / 支持软件

- JDK 21 运行时；
- Spring Boot 3.4.3 应用框架；
- OceanBase / MySQL 兼容数据库（数据持久化）；
- Redis（缓存与会话）；
- Knife4j（接口文档自动生成）；
- 配套服务：爱予慧AI语音交互服务系统（Python 语音核心，配置数据消费方）。

## 编程语言

Java 21。

## 源程序量

约 79000 行（取 manager-api Java 源代码实测约 7.9 万行，含注释）。

## 开发目的

为 AI 语音陪伴硬件产品线提供统一管理后端服务，承载设备注册绑定、智能体配置、NFC 写卡与领取、声音克隆、知识库、支付订阅、故事引擎等全业务管理能力，并作为语音核心服务的配置中枢实现智能体参数运行时热下发，支撑产品规模化运营。

## 面向领域 / 行业

人工智能物联网（AIoT）、AI 语音陪伴智能硬件、情感陪伴科技行业的后端服务软件领域。

## 软件的主要功能

1. 设备管理：设备注册、绑定/解绑智能体、OTA 固件升级、通讯录与权限；
2. 智能体管理：智能体配置 CRUD、配置快照回溯、声纹、MCP 接入点、模板、聊天历史；
3. 远程配置下发：智能体参数持久化，供 Python 服务端拉取热重载，无需重启即生效；
4. NFC 写卡与领取：产品类型、批次、资产、写卡任务、领取、Scheme、操作日志全生命周期管理；
5. 宠物与陪伴上下文：宠物档案、记忆、聊天、故事、陪伴上下文管理；
6. 声音克隆：声音样本上传、克隆任务提交、声音资源管理；
7. 知识库：知识库与知识文件管理，供检索增强；
8. 支付与订阅：订单、支付回调、订阅周期管理；
9. 故事引擎：宠物故事节点编排与上下文推进；
10. 系统管理：管理员、字典、参数、操作日志、服务端管理。

## 软件的技术特点

- 基于 Spring Boot 分层架构（接入/控制/服务/持久化四层）；
- Apache Shiro 过滤器链 + 权限注解实现粗细两级鉴权；
- MyBatis-Plus 通用 CRUD 降低样板代码；
- Liquibase 版本化数据库迁移保证多环境数据一致；
- 操作日志切面无埋点审计、幂等切面保护支付回调；
- 作为配置中枢实现智能体参数运行时热下发；
- Knife4j 自动生成接口文档。
