# 03: 编辑小物件 + 列表内启用/停用

**What to build:** 运营在列表操作列点"编辑"，弹窗回填当前的类型、图片、故事，可替换图片、改写故事、换类型；当前类型在编辑态始终可选（不会因为"这个类型已被自己占用"而被过滤掉），其他已被占用的类型仍不出现在下拉里。运营在列表里直接点"启用/停用"切换状态，切换只提交 id 与目标状态，不回传图片与故事——因此不会覆盖他人刚改过的故事内容。

**Blocked by:** 02

**Status:** resolved

- [x] 更新接口：全量更新类型、图片、故事；唯一性校验排除自身 id，保留原类型不报重复；类型改为另一个未被占用的类型可成功
- [x] 单独的"更新状态"接口，只接收 id 与目标状态，不读写图片与故事
- [x] 更新接口对不存在或已删除的记录返回"物件不存在"，不做静默成功
- [x] 弹窗区分新增与编辑：编辑态标题与按钮文案区分，编辑时把当前类型并入可选列表
- [x] 列表操作列出现"编辑"与"启用/停用"，状态列展示启用/停用标签
- [x] 切换状态成功后刷新列表并给出提示；失败时把后端返回的错误信息展示出来
- [x] Service 集成测试：更新成功、改为已被占用类型被拒绝、保留自身类型不报重复、改类型到未占用类型成功、更新不存在记录报"物件不存在"、更新状态不影响图片与故事
