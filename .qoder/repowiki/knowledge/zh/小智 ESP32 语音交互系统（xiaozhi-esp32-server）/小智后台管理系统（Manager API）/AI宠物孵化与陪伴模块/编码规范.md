- Controller 方法统一使用 `@AllArgsConstructor` 构造器注入 Service，并通过 `xiaozhi.common.utils.Result<T>.ok()` 包装返回值。
- 需要用户鉴权的接口在 Controller 方法上标注 `@RequiresPermissions("sys:role:normal")`，并在 Service 中通过 `SecurityUser.getUserId()` 获取当前用户 ID 做归属校验。
- 业务异常统一抛出 `RenException(ErrorCode.XXX)`，错误码集中在 ErrorCode 枚举中。
- Entity 使用 Lombok `@Data` + MyBatis-Plus `@TableName`/`@TableId`/`@Schema` 注解，审计字段通过 `@TableField(fill = FieldFill.INSERT|UPDATE)` 自动填充。
- 配置类使用 `@Component` + `@ConfigurationProperties(prefix = "xxx")` 形式注入，并提供 `isConfigured()` 等便捷判断方法。
- Service 实现类继承 `BaseServiceImpl<Dao, Entity>` 并使用 `@RequiredArgsConstructor` 注入依赖，事务方法标注 `@Transactional(rollbackFor = Exception.class)`。
