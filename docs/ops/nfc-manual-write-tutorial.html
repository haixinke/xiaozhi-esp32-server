NFC 蛋宝宝全生命周期实操

00

开工前检查

三样东西没准备好，后面每一步都会卡住。先逐项确认。

账号权限：你的管理后台账号是 superAdmin，顶部导航能看到「NFC 生产管理」下拉菜单。看不到就不是超管，找管理员提权。
微信侧已就绪：进入「NFC 生产管理 → 商品类型」，确认唯一商品类型的「发布就绪」列显示已就绪。若未就绪，点「登记发布证据」填入发布版本、发布时间、冒烟证据。这一步没做，第 02 步生成 Scheme 会被服务端拒绝。
手机与工具：一部支持 NFC 的手机，安装 NFC Tools（或同类 NFC 写入 App）。Android 和 iPhone 都可以；Android 多一步写 AAR 记录，教程里会标注。
空白 NFC 标签若干：NTAG 系列即可。小批量验证建议 5–10 张，预留写坏的损耗。
环境说明

管理后台默认地址 http://localhost:8001（开发环境）。本教程对应手动模式（小批量验证）；工厂 CSV 模式在弹窗中标注「暂不可用，验证阶段仅支持手动模式」，本教程不使用。

01

创建批次

批次 = 同一 SKU、同一原型的一窝蛋。建批次时服务端会为每个资产生成唯一的 asset_no、wechat_sn、claimRef。

电脑端 · 管理后台
  1. 顶部菜单「NFC 生产管理 → 批次管理」。
  2. 点右上角 创建批次。
  3. 填写弹窗字段：批次号（自定义，如 B20260830-01）、商品类型（固定蛋宝宝 NFC）、SKU 编码、原型（如 锦鲤）、计划数量（1–10000，小批量填 5–10）、备注（可空）。
  4. 点 确定。列表出现新批次，状态为 草稿。
批次：无→草稿
02

生成 Scheme

Scheme 是微信返回的 openlink——最终写进 NFC 芯片的内容。每件资产生成一个，后台异步逐件调用微信接口。

电脑端 · 管理后台
  1. 「批次管理」列表里，找到状态为 草稿 的批次，点行内 生成Scheme（只有草稿状态才显示这个按钮）。
  2. 批次状态变为 Scheme生成中。点 查看Scheme进度 打开进度弹窗，盯「进度 / 已处理 / 错误信息」。
  3. 全部成功后可看到批次状态变为 就绪。数量少时十几秒，上千件需要等几分钟。
草稿→Scheme生成中→就绪
失败怎么办

进度弹窗显示「失败 / 部分成功」时，先看错误信息：model_id 未配置、领取页未发布属于配置问题，修好再点 重试；微信临时超时可直接重试。任务卡住可点 取消，取消后批次回到 草稿 可重新发起。

03

创建写卡任务（手动模式）

写卡任务把这一批资产"锁定"为待写状态，并决定用哪种方式写。模式创建时选定，不可变更。

电脑端 · 管理后台
  1. 批次状态为 就绪 时，行内出现 创建写卡任务，点击。
  2. 弹窗中保持默认选中 手动模式（小批量验证）。「工厂 CSV 模式」为灰色不可选，属正常。
  3. 点 创建。批次状态变为 写卡中，写卡任务状态为 已创建。
就绪→写卡中＋任务：已创建
如果建错了

进入「NFC 生产管理 → 写卡任务」，对该任务点 取消。任务变为「已取消」，资产占用自动释放，批次回退到 就绪，可以重新创建任务。已导入过写卡结果的任务不能取消。

04

逐张写卡

核心工序。每张卡四个动作：复制 Scheme → 手机写入 → 标记已写入。逐张来，写完一张再碰下一张。

电脑端 · 进入手动写卡页
  1. 「NFC 生产管理 → 写卡任务」，找到状态为 已创建 的手动任务，点 手动写卡。
  2. 「手动写卡」页，每张资产一张卡片，状态初始为 待写入，卡片上能看到 SN、原型和验证方式（触碰自验证 / 人工确认）。
电脑端 · 每张卡
  1. 点资产卡上的 复制 Scheme，该条明文 Scheme 进入剪贴板。每次查看都会记审计日志，属于正常留痕。
  2. 写入完成后回到这张卡，点 已写入（必须先复制过 Scheme 才能点）。
手机端 · NFC Tools
  1. 打开 NFC Tools，选择「写 → 添加记录 → URL/URI」，粘贴刚复制的 Scheme。
  2. 仅 Android：再添加一条「应用记录（AAR）」，包名填 com.tencent.mm。iPhone 写不了 AAR，跳过即可，不影响使用。
  3. 把手机靠近空白标签，执行写入，等 App 提示成功。
待写入→已写入待验证
写坏了

手机写入中断、写错内容：在该资产卡上点 写坏了，状态回退到 待写入，重新复制 Scheme 重写即可。资产留在任务内，不会丢。

05

验证卡

确认芯片里的内容和系统记录一致。首选"触碰自验证"：用手机真碰一次，系统自动完成验证。

手机端 · 触碰自验证（首选）
  1. 用手机直接触碰刚写好的标签。
  2. 微信自动拉起，打开蛋宝宝小程序领取页（此时商品未激活，页面提示无法领取，属正常）。
  3. 这一碰后台已命中 preview 接口，资产自动变为 已验证（验证来源记为 TOUCH）。
电脑端 · 人工兜底
  1. 手机碰不了（如 iPhone 刚写完无法当场碰）：用 NFC Tools「读」标签，比对读出的 URI 与后台 Scheme 一致。
  2. 确认无误后，在资产卡上点 验证通过，状态变为 已验证（验证来源记为 MANUAL）。
已写入待验证→已验证
放心碰

触碰自验证只对"本任务内、已标记已写入"的资产生效。随手碰一张别的卡不会改变任何状态，也不会触发领取。

06

锁卡

把标签设为只读，内容再也无法改写。这是防篡改的最后闸门，顺序必须在验证通过之后。

手机端 · NFC Tools
  1. 用 NFC Tools 对标签执行「锁定 / 设为只读」操作，贴卡确认。
电脑端 · 手动写卡页
  1. 资产状态为 已验证 时，卡片出现 已锁卡，点击。
  2. 弹窗确认：「锁卡不可逆，锁错即废卡。确认已用手机 NFC 工具完成锁卡？」→ 点 已锁卡，确认。
不可逆

锁卡是物理层面的只读熔断，后台无法解锁。锁过的卡发现内容写错，只能把资产报废、补写新卡。点确认前，确保手机端真的已经锁了。

07

锁后复验

锁完再碰一次，确认锁定后标签仍可读、内容没变。这是入库前的强制人工复核。

手机端 + 电脑端
  1. 手机再次触碰已锁的标签，微信正常拉起领取页即通过。
  2. 回到手动写卡页，该资产卡片由「已锁卡（待复验）／请再触碰一次完成锁后复验」变为「已锁卡（复验通过）／可入库」。
  3. 全部资产都显示「可入库」后，本批次的写卡环节结束。
入库门禁

手动模式的资产必须满足「已锁卡 + 锁后触碰复验通过」才允许入库，服务端硬校验，绕不过去。某张卡没复验就批量入库，会被整批拒绝并提示异常资产。

08

入库

实物进仓库，系统里资产从"已验证"变"已入库"。已入库 ≠ 可领取，还差最后一步激活。

电脑端 · 管理后台
  1. 「NFC 生产管理 → 资产管理」，用筛选栏（批次 ID / 状态=已验证）圈出本批资产。
  2. 勾选要入库的资产（点表头全选本批），点 批量入库。
  3. 步骤 1：填 入库单号（仓库单据号）和 备注，点「下一步」。
  4. 步骤 2：核对入库资产数、单号、请求 ID，点 确认入库。
  5. 步骤 3：看到「入库成功」。资产状态变为 已入库。
已验证→已入库
整批校验

入库是全量校验：只要勾选的资产里有一张状态不对（未验证、未锁卡），整批不入库并提示异常资产。修正后重新提交即可，同一次重试复用请求 ID 不会重复入库。

09

出库激活

商品卖出/发货时出库扫描激活。只有激活后，用户触碰才能真正领取——这是防止库存商品被提前领走的闸门。

电脑端 · 管理后台
  1. 访问「扫码出库激活」页：地址栏直接输入 /pdc-nfc/activation（该页不在菜单里，属正常）。
  2. 扫码枪扫描或手动输入资产编号，按回车逐条添加。系统自动查询状态，只有"已入库"的资产显示可激活，最多 500 条。
  3. 填 激活单号（出库业务单号）。
  4. 点 激活 N 项资产，结果弹窗显示「激活成功」。
已入库→已激活
为什么要激活

已写卡、已入库的商品在仓库里被 NFC 手机碰到时，后端会提示"暂时无法领取"。只有出库激活（ACTIVE）的资产才允许领取，确保领取动作只发生在商品真正到达买家之后。

10

真机领取测试

全链路的最后一环：模拟真实买家，从触碰到领养一只蛋宝宝。

手机端 · 用户视角
  1. 手机触碰已激活的标签，微信拉起蛋宝宝小程序领取页。
  2. 按提示登录、绑定手机号。
  3. 看到蛋宝宝原型预览，点「立即领取」。
  4. 领取成功，进入孵化流程。
电脑端 · 核验
  1. 「资产管理」找到该资产，状态应为 已领取。
  2. 点开资产详情，「状态时间线」应完整呈现：已创建 → Scheme已生成 → 已写入 → 已验证 → 已入库 → 已激活 → 已领取。
  3. 再用另一台手机碰同一张卡，应提示"已被领取"，不能重复领。
已激活→已领取
通关标准

同一台手机重复触碰返回同一只宠物；他人触碰提示已领取。两条都满足，说明幂等与防重复领取都工作正常，本教程全流程通过。

排障速查

按"看到的现象"查。所有状态名称与后台页面显示一致。

现象原因处理
批次行内没有「生成Scheme」按钮批次不在「草稿」状态按钮仅草稿显示；若卡在「Scheme生成中」，点「查看Scheme进度」取消后重来
生成 Scheme 被拒model_id 未配置 / 领取页未发布 / 发布证据未登记到「商品类型」页登记发布证据；配置问题找研发
没有「创建写卡任务」按钮批次不在「就绪」状态等 Scheme 全部生成完；或写卡任务已存在（批次已是「写卡中」）
写卡任务取消后批次仍「写卡中」旧版本缺陷，已修复升级后端后取消会自动回退「就绪」，可重建任务
手动写卡页点不了「已写入」还没复制过 Scheme先点「复制 Scheme」，按钮才会解锁
触碰标签微信没反应URI 未写入 / 写入失败NFC Tools 读卡确认有 URI 记录；没有则点「写坏了」重写
领取页提示"暂时无法领取"资产未激活正常防提前领取；走第 09 步激活
批量入库被拒，提示「手动模式资产未锁卡，禁止入库」勾选资产里有未走第 06 步锁卡的回手动写卡页补锁卡
批量入库被拒，提示「锁后未完成触碰复验，禁止入库」锁了卡但没做第 07 步复验逐张再触碰一次，卡片变「可入库」再入库
锁卡后发现内容写错锁卡物理不可逆资产报废，补写新卡
