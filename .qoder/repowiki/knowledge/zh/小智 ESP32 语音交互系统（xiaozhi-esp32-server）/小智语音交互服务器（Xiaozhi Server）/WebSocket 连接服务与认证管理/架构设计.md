本模块由三个文件构成清晰的三层结构：
- `websocket_server.py`：进程级入口，定义 `WebSocketServer` 类，使用 `websockets.serve` 启动服务，维护全局连接数上限（`_max_connections`）与活跃计数（`_active_connections`），在握手前通过 `_http_response` 拦截普通 HTTP 请求，通过 `_handle_auth` 完成鉴权后再创建 `ConnectionHandler`。
- `connection.py`：连接级核心，`ConnectionHandler` 封装单个 WebSocket 会话的全部状态（VAD/ASR/TTS/LLM/Memory/Intent 组件、对话历史、声纹识别、AEC 回声消除、Opus 解码器、超时任务等），通过 `_route_message` 区分文本与二进制音频消息，异步后台初始化差异化配置并动态加载模块。
- `auth.py`：无状态的 `AuthManager`，基于 HMAC-SHA256 + Base64 生成/验证 `client_id|username|timestamp` 三元组 token，支持白名单设备免校验。
依赖方向单向：`websocket_server` → `connection` + `auth`；`connection` 仅依赖工具模块与 providers，不反向引用 server。
