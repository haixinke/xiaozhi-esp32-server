本模块由四个核心文件组成，职责清晰分层：
- `config_loader.py`：配置加载核心。提供 `read_config` 读取 YAML、`load_config` 合并默认配置 `config.yaml` 与用户覆盖 `data/.config.yaml`，当检测到 `manager-api.url` 时通过 `get_config_from_api_async` 从远端拉取配置；`merge_configs` 实现递归深度合并；`ensure_directories` 自动创建日志、ASR/TTS 输出等目录。
- `settings.py`：启动时校验配置文件存在性，并检测是否同时包含本地与 API 配置冲突。
- `manage_api_client.py`：基于 httpx 的异步 HTTP 客户端单例，按事件循环维护独立连接池，内置重试机制（可配置 `max_retries`/`retry_delay`），封装 `/config/server-base`、`/config/agent-models`、`/config/correct-words` 等接口，并将业务错误码映射为 `DeviceNotFoundException` / `DeviceBindException`。
- `logger.py`：基于 loguru 的日志初始化，从配置中读取格式、级别、轮转策略，并通过 `create_connection_logger` 为每个连接绑定独立的 `selected_module` 字符串。
- `assets/`：静态音频资源（bind_code 0-9.wav、wakeup_words.wav、tts_notify.mp3 等）。
依赖方向：`settings` → `config_loader` → `manage_api_client`；`logger` 依赖 `config_loader` 和 `settings` 获取配置；所有配置最终通过 `cache_manager`（来自 `core.utils.cache.manager`）缓存。
