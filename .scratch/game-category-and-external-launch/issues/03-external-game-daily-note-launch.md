# 03: 从小纸条打开外部游戏

**What to build:** 当首页小纸条抽到已启用的外部游戏时，用户可以从游戏邀请在小程序内打开 H5，同时按原规则获得小纸条连续奖励。

**Blocked by:** [02 配置外部游戏并从百宝箱活动打开](02-external-game-activity-launch.md)

**Status:** resolved

## 验收标准

- [ ] 用一条已启用、配置了小纸条入口的外部游戏作为隔离测试数据。查询当日小纸条时，嵌套 `game` 返回分类和完整链接。仍从符合现有启用状态和入口筛选的游戏中随机选择，停用或移除小纸条入口后不会抽到该游戏。
- [ ] 打开符合领取条件的小纸条时按现有规则发放连续奖励。随后点击外部游戏邀请，进入百宝箱活动已使用的 `web-view`，并保留查询参数和锚点。打开或重复游玩 H5 不产生游戏扣费、奖励或次数记录。
- [ ] 沿用首页现行的小纸条展示门槛。链接无效、导航或加载失败时给出提示，用户可留在入口或返回。内部游戏和缺少分类的旧响应仍按游戏类型分流，一起画保留小纸条来源标记。
- [ ] 用现有小纸条服务和首页测试覆盖抽取及响应契约、外部跳转、异常提示、打开纸条领奖和原生分流。
