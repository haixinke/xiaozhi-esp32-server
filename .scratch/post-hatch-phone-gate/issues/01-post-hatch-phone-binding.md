# 01: 破壳后强制绑定手机号闭环

**What to build:** 蛋宝宝破壳动画结束且服务端确认破壳成功后，未绑定手机号的用户进入必须完成的绑定界面。用户主动授权并完成服务端绑定后才能继续使用后续功能；拒绝或失败时保留破壳成果并可重试。该闭环同时适用于存量账号、退出重进及多宠物场景，并为两种领取渠道提供统一的破壳后手机号门槛。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 破壳动画播放完成且服务端确认成功后才展示绑定界面；接口先返回时不提前打断动画，动画先结束时等待接口结果。
- [x] 视频加载失败沿用现有破壳收尾方式，仍以服务端结果决定是否进入绑定界面；破壳请求失败不误判为成功，可恢复并重试。
- [x] 绑定界面说明手机号用于后续手机号登录，保留可访问的隐私说明及用户主动同意动作；本次交付范围只包含绑定时机调整。
- [x] 用户主动点击授权按钮才拉起微信手机号授权；不提供跳过绑定的产品入口，不自动反复调用原生授权。
- [x] 用户拒绝授权、授权结果缺失或绑定失败时，停留在绑定界面并允许重试；已保存的破壳结果、宠物及破壳首卡保持完整。
- [x] 重复点击或请求尚未完成时不产生重复绑定、重复跳转或提前放行；只有服务端确认绑定成功后才恢复后续功能，并同步当前账号的绑定状态。
- [x] 存量已破壳未绑定账号、冷启动、回到前台、动画期间退出后重进，均可恢复到相同绑定流程；未完成绑定不能通过返回、切换页面或当前宠物绕过门槛。
- [x] 门槛按账号生效：账号持有已破壳宠物且未绑定时需要绑定；已绑定账号直接继续，其他宠物再次破壳不重复要求绑定。
- [x] 直接打开后续页面、使用已有设备标识或调用后续业务接口，均不能绕过服务端的手机号约束；不得仅凭本地绑定标志放行。
- [x] 必要的静默登录、账号及宠物状态恢复、手机号绑定、隐私说明访问保持可用；共同门槛不前置到领取、孵化或破壳接口。两种领取渠道的原有手机号拦截由后续对应任务移除。
- [x] 先写失败测试再实现，覆盖动画与接口先后顺序、视频异常、拒绝授权、缺少授权结果、绑定失败与重试、并发点击、存量账号、多宠物、重进恢复及页面/API 直接访问；相关行为通过页面与服务端边界验证。
- [x] 完成相关前后端回归及工程检查，变更逻辑的有效测试覆盖率至少 80%；日志和测试输出不暴露手机号、授权凭据或会话凭据。
- [x] 同步破壳后手机号门槛、恢复行为和手机号用途的现行说明，纠正破壳成功后自动进入收藏卡页的旧描述；保持原有孵化期命名流程。
