- 各能力域（ASR/TTS/LLM/Memory/Intent/VAD/VLLM）均遵循 base.py 抽象基类 + 多实现的插件式结构，通过配置项 provider 字段在运行时切换具体后端。
- 配置统一经 config/settings.py 的 load_config() 加载，支持本地 YAML 合并与 read_config_from_api 远程覆盖，auth_key 优先级为 server.auth_key > manager-api.secret > 随机生成。
- HTTP 接口基于 aiohttp 的 SimpleHttpServer 注册路由，统一处理 CORS、认证与异常返回格式。
- WebSocket 消息处理采用 textMessageHandlerRegistry 注册表模式，新消息类型只需实现 Handler 并注册即可被自动路由。
- 插件函数通过 plugins_func/register.py 的装饰器机制自动发现加载，无需手动维护依赖列表。
- 异步任务统一通过 asyncio.create_task 启动，退出时集中 cancel 并 await asyncio.wait 等待终止。
