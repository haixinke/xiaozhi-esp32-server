模块采用经典的 Controller → Service → Dao/Entity 分层结构，并辅以 DTO/VO/Enums/TypeHandler 等辅助包：
- controller：基于 Spring MVC 的 REST 控制器，统一通过 `@Tag` + `@Operation` 生成 OpenAPI 文档，使用 `@RequiresPermissions` 做接口级权限控制。
- service：接口定义在 `service/` 下，实现放在 `service/impl/`；其中聊天历史上报等复杂业务抽到 `service/biz/` 子包中独立接口与实现，便于跨层复用。
- dao：继承自 `BaseDao<T>` 的 MyBatis Mapper 接口，部分查询使用 `@Select` 注解直接写 SQL，复杂聚合查询通过 XML 或 VO 映射完成。
- entity：对应数据库表（如 `ai_agent`），使用 MyBatis-Plus 注解标注主键策略与表名。
- dto/vo：入参用 DTO 校验（`@Valid`），出参用 VO 封装，避免实体直接暴露。
- typehandler：自定义 `ContextProviderListTypeHandler` 将 JSON 字段与 `List<ContextProviderDTO>` 互转，兼容 MyBatis-Plus 3.5.6+。
- Enums：存放枚举与常量（如 MCP JSON-RPC 类型、快照字段等）。
依赖方向严格单向：Controller → Service → (Service impl → Dao/Entity)，并通过 RedisUtils 做短期缓存（如音频播放令牌）。
