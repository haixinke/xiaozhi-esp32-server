- 每个脚本以类封装测试逻辑（如 `ASRPerformanceTester`、`StreamTTSPerformanceTester`），并提供 `run()` 异步方法作为统一入口，`main()` 仅负责实例化并调用 `run()`。
- 被测实例通过 `create_instance(module_type, config)` 工厂函数按配置的 `type` 字段动态创建，避免硬编码具体供应商实现。
- 所有外部 I/O 调用都包裹在 `try/except` 中，并通过 `asyncio.wait_for(..., timeout=10.0)` 设置超时，失败时返回包含 `errors: 1` 和 `error_type` 的结果字典。
- 测试结果统一以字典形式返回，成功时 `errors: 0` 并包含平均耗时/首 Token 时间，失败时记录 `error_type`（如「502网络错误」「超时连接」「配置错误」）。
- 结果打印使用 `tabulate` 生成 grid 格式表格，有效结果按平均耗时升序排列，错误结果统一追加到表格末尾。
- 配置校验阶段跳过未填写有效密钥的配置项（检测 `你的`、`placeholder`、`sk-xxx`、`none`、`null`、空字符串等占位符），避免误测。
