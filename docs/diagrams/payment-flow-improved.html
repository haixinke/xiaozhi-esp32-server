小程序微信支付流程 - 改造方案

回调 + 前端主动查单 + 定时任务兜底，三道防线保证支付一致性

第一道防线：微信回调

  • • 微信主动通知后端支付结果
  • • 正常情况最快、最可靠
  • • 后端必须返回 SUCCESS 和 HTTP 200
  • • 处理逻辑需要幂等防重

第二道防线：前端主动查单

  • • wx.requestPayment success 后立刻触发
  • • 即时性强，用户体验最好
  • • 直接调用微信支付查单 API 确认
  • • 适合用户停留在支付结果页的场景

第三道防线：定时任务兜底

  • • 每 5 分钟扫描临近过期 PENDING 订单
  • • 用户关闭小程序后仍能补偿
  • • 捕获回调和前端都失败的极端情况
  • • 最后一道安全网
