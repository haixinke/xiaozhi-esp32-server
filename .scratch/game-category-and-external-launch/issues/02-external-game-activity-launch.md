# 02: 配置外部游戏并从百宝箱活动打开

**What to build:** 运营在智控台保存并启用一条外部游戏后，用户可从百宝箱活动在小程序内打开对应 H5。停用和重新启用能控制投放并保留原配置。

**Blocked by:** [01 内部游戏分类与存量兼容](01-internal-game-classification.md)

**Status:** resolved

## 验收标准

- [ ] 智控台列表展示「外部游戏」，新增或编辑可选择外部分类、填写或回显跳转链接并选活动、小纸条或两者。外部游戏的奖励、费用和每日上限均固定为 `0`，一起画和听你说的分类固定为内部。
- [ ] 后端允许保存有有效主机名且无用户名或密码的完整 HTTPS 链接，去除首尾空白并保留查询参数和锚点。未知分类、外部游戏缺失或填写无效链接、任一结算字段非零、原生保留类型改为外部，均返回校验错误。沿用现有字典和入口校验。
- [ ] 修改外部游戏链接后以新地址为准。启停保留分类、链接及入口，停用后活动列表不再返回，重新启用后恢复。旧智控台的更新请求缺少分类时保留原分类和链接，仍按原分类校验。显式改为内部游戏后，管理端和活动查询均不再返回旧链接。
- [ ] 活动页点击 `EXTERNAL` 游戏进入可供小纸条复用的 `web-view` 页面，传入的 HTTPS 地址完整还原。小程序凭证和账号信息不随链接传递。无效链接、导航或加载失败时有可理解的提示，用户可留在活动页或返回。
- [ ] 活动页沿用现有破壳与手机号约束。外部游戏显示「去玩」，重复打开不触发游戏星星奖励、扣费或计次。内部游戏以及旧响应缺少分类时继续使用原有路由和提示。
- [ ] 使用同一条测试配置验证后端保存与活动列表查询、智控台编辑及启停请求、活动页分流和地址传递。新增页面通过小程序工程完整性校验。
