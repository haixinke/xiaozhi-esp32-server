- Controller 方法统一返回 `Result<T>` 包装，参数校验使用 `@Valid`，接口文档通过 `@Tag`、`@Operation`、`@Parameter` 描述。
- 权限校验在 Controller 层通过 `@RequiresPermissions("sys:role:...")` 声明，并在方法内调用 `agentService.checkAgentPermission` 进行资源级二次校验。
- Service 实现继承 `BaseServiceImpl<Dao, Entity>` 并使用 `@AllArgsConstructor` 注入依赖，异常统一抛出 `RenException(ErrorCode.XXX)`。
- DAO 接口继承 `BaseDao<T>`，简单查询使用 `@Select` 注解内联 SQL，复杂查询通过 VO 映射返回。
- 实体类使用 Lombok `@Data` + MyBatis-Plus `@TableName`/`@TableId` + Swagger `@Schema` 注解组合定义。
- DTO/VO 与 Entity 分离，转换通过 `ConvertUtils` 或手动赋值，禁止直接将 Entity 作为 API 响应。
