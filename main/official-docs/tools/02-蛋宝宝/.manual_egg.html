一、系统概述

爱予慧蛋宝宝AI宠物小程序软件是上海爱予慧科技有限责任公司独立开发的 AI 宠物养成微信小程序，面向移动端用户，提供蛋宝宝孵化、AI 对话、NFC 领取、收藏卡、涂鸦相册等陪伴式养成体验，与 ESP32 智能语音终端及智控台管理平台形成完整产品生态。

小程序采用微信原生框架开发（WXML/WXSS/JavaScript），通过 HTTPS 接入后端 RESTful API 获取业务数据，本地维护宠物状态机与场景渲染逻辑，支持弱网环境下的兜底展示。界面以孵化前后的三屏生活空间为核心，配合定时故事状态切换与背景轮播，营造持续在线的陪伴感。

本手册面向软件登记审查与运营人员，说明小程序的运行环境与各功能页面的操作方法。

1.1 运行环境

客户端：微信小程序运行环境，支持 iOS 与 Android 微信客户端。服务端：Java 21 + Spring Boot 3 后端、MySQL 兼容数据库与 Redis 缓存。小程序通过 HTTPS 调用后端接口，资源文件由 OSS 对象存储提供。

1.2 欢迎与授权

用户首次打开小程序进入欢迎页，完成微信授权登录后进入主界面。授权信息用于建立用户身份与宠物归属关系。

1.3 首页

首页为孵化前的蛋宝宝展示界面，呈现蛋的当前形态与孵化进度，是用户进入养成流程的入口。页面底部提供主要功能导航。

二、孵化养成

孵化养成是小程序的核心业务流程，覆盖从孵化引导、取名、心愿设定到课程互动的完整链路，驱动蛋宝宝从蛋形态到破壳后的成长。

2.1 孵化引导

孵化引导页向用户说明孵化条件与操作步骤，引导用户完成孵化前置准备，进入取名环节。

2.2 取名

取名页供用户为蛋宝宝设定昵称，命名后即建立用户与宠物的专属陪伴关系。

2.3 心愿

心愿页展示心愿问卷，用户回答后生成专属心愿，作为后续养成内容与故事推进的依据。

2.4 课程

课程页提供分龄互动课程内容，按用户年龄段推荐对应课程，完成课程可推进宠物成长进度。

三、NFC 领取与设备绑定

3.1 NFC 领取

NFC 领取页在用户触碰实体 NFC 标签后打开，完成宠物领养与标签资产绑定。页面展示领取结果与关联的宠物形态。

3.2 添加设备

添加设备页引导用户绑定 ESP32 智能语音终端，建立小程序与硬件设备的关联，使宠物具备语音交互能力。

四、互动内容

4.1 收藏卡

收藏卡页展示宠物在养成过程中获得的主题卡片，以图集形式呈现，供用户浏览与回顾。

4.2 相册

相册页汇集宠物的涂鸦作品与成长记录图片，支持查看与分享。

4.3 聊天

聊天页提供与蛋宝宝的 AI 对话界面，用户可通过文字与语音进行交互，对话内容由后端大模型实时生成。

4.4 聊天设置

聊天设置页用于调整对话相关参数，如语音播报开关等，个性化用户的交互体验。

五、个人中心

5.1 我的

我的页为用户个人中心入口，汇总展示宠物概况、功能入口与账号信息。

5.2 资料

资料页展示与编辑用户个人信息，包括昵称、头像等。

5.3 账号

账号页提供账号绑定与安全设置，支持微信账号关联管理。

5.4 设置

设置页提供小程序通用设置项，包括通知、缓存等系统级配置。

六、年龄与邀请

6.1 年龄段

年龄段页供用户选择或调整所属年龄区间，系统据此推荐匹配的分龄课程与内容，保障内容适龄性。

6.2 邀请码

邀请码页展示用户的专属邀请码，支持分享给好友，邀请成功后获得相应奖励。

七、帮助与合规

7.1 反馈

反馈页供用户提交诉求与意见。每条反馈生成唯一受理编号，便于追溯。按产品规则反馈不回复用户。

7.2 帮助

帮助页提供常见问题与使用指引，辅助用户快速上手。

7.3 注销

注销页提供账号注销功能，用户可在此申请注销账号并清除相关数据。

7.4 隐私政策

隐私政策页展示小程序的隐私信息收集与使用说明，满足合规要求。

7.5 用户条款

用户条款页展示服务协议内容，明确用户与服务提供方的权利义务。
