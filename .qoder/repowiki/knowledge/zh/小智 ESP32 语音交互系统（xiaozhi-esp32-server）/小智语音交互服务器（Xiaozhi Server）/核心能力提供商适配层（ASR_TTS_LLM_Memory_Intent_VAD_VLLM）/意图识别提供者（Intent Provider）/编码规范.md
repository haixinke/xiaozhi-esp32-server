- 每个实现类均命名为 IntentProvider 并继承 IntentProviderBase，通过所在子包路径区分不同策略实现。
- 日志记录统一使用 TAG = __name__ 配合 logger.bind(tag=TAG).info/debug/error(...) 模式。
- 异步 LLM 调用一律通过 asyncio.to_thread 包装同步方法，避免阻塞事件循环。
- 异常分支统一回退为固定 JSON 字符串 '{"function_call": {"name": "continue_chat"}}' 作为默认意图。
- 所有 detect_intent 实现签名保持一致：(self, conn, dialogue_history: List[Dict], text: str) -> str，返回纯 JSON 字符串而非 Python 对象。
