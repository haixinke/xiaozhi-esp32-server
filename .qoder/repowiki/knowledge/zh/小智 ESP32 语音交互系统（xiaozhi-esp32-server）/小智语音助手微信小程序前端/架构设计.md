模块遵循微信小程序标准工程结构：`app.js` 为全局入口，通过 `globalData` 集中管理 token、userId、agentId、wsUrl/wsToken、订阅状态等跨页面共享数据；`app.json` 声明 tabBar（聊天/我）及所有页面路由。

分层清晰：
- `pages/` 按业务域划分（index 聊天、companion/* 伴侣配置子页、destiny/soul-resonance/memory-anchor 命运与记忆、voice-call 语音通话、orders/subscription/backpack/settings 等），每个 Page 独立 .js/.wxml/.wxss/.json，部分复杂页面拆出 `logic.js` 分离业务逻辑。
- `components/` 提供可复用 UI 组件（chat-bubble 聊天气泡、floating-call-ball 悬浮通话球、reshape-confirm 确认弹窗、voice-button 语音按钮）。
- `utils/` 封装底层能力：`request.js` 统一 HTTP 请求（自动 Bearer Token + 401 静默重试）、`websocket.js` 实现带心跳/指数退避重连的 WebSocketManager 状态机、`audio.js` 与 `voice-call-manager.js` 管理录音/播放、`auth.js`/`device.js`/`theme.js`/`logger.js` 等工具。
- `libs/opus/` 通过 `opus-runtime.js` 抽象 Opus 编解码器，优先加载 `libopus.wasm`（WXWebAssembly），不可用时回退到 JS stub，保持 API 一致。
- `config/` 存放静态配置（伴伴随机码、声音目录）。依赖方向单向：pages → components/utils/libs，app.js 作为唯一全局状态源，页面间通过 getApp().globalData 通信，无反向依赖。
