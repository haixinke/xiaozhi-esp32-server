- 插件 provider 统一通过 `create_instance(class_name, *args, **kwargs)` 工厂函数动态导入 `core.providers.<module>.<class_name>` 并实例化，未找到时抛出 ValueError。
- 所有可缓存的数据通过 `core.utils.cache.manager.cache_manager` 单例访问，并使用 `CacheType` 枚举作为命名空间键，key 通常拼接业务标识（如 `device_prompt:{device_id}`）。
- 模块初始化函数（initialize_tts/initialize_asr 等）统一从 config["selected_module"][<TYPE>] 读取模块名，再解析 type 字段确定具体实现类名。
- 日志统一通过 `from config.logger import setup_logging` 获取 logger，并以 `TAG = __name__` 绑定 tag 输出结构化日志。
- 异步 I/O 操作（如天气查询）通过 `conn.loop.call_soon_threadsafe` 提交到事件循环，并用 threading.Event 同步等待结果以兼容非 asyncio 调用方。
- 音频处理函数默认采用 16kHz、单声道、16bit 小端 PCM 作为中间格式，并通过 60ms 帧长分块编码/解码。
