- 所有日志输出统一通过 `self.logger.bind(tag=TAG).xxx(...)` 形式，便于按模块标签过滤。
- 异步资源清理采用 try/finally 模式，确保连接关闭、计数器递减、记忆保存等操作在任何异常路径下都能执行。
- 模块初始化通过 `initialize_modules` 工厂函数按 `selected_module` 配置动态加载 VAD/ASR/LLM/Memory/Intent 等组件，而非硬编码实例化。
- 认证流程遵循「先认证后建立连接」原则，未通过 `AuthManager.verify_token` 或不在白名单的设备直接拒绝握手。
- 长耗时操作（组件初始化、记忆保存、标题生成）通过 `asyncio.create_task` 或 `threading.Thread` 异步/后台执行，避免阻塞主事件循环。
