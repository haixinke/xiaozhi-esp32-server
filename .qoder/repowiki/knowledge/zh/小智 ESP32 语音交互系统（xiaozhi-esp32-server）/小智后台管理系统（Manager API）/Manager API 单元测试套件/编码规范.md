- 每个被测类或关键分支在 test 目录下有同名或后缀为 Test.java 的独立测试类，包路径与生产代码保持一致。
- 单元测试统一使用 JUnit 5 + Mockito，通过 `@ExtendWith(MockitoExtension.class)` 和 `@Mock` 注入依赖，避免启动 Spring 容器。
- 对静态工具类（`SecurityUser`、`MessageUtils`、`SqlHelper`、`RedisUtils`）采用 `mockStatic` 进行隔离，并在 try-with-resources 中管理生命周期。
- 测试用例使用 `@DisplayName` 注解描述业务场景，断言优先使用 AssertJ 的 `assertThat` / `assertThatThrownBy` 配合 `ArgumentCaptor` 验证交互。
- 需要 Spring 上下文的行为（如 i18n、`@Value` 注入）通过反射直接设置静态字段或 Mock `ApplicationContext.getBean` 来模拟。
