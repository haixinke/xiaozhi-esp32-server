采用典型的 Vue2 SPA 分层架构：入口 `src/main.js` 初始化 Vue 实例并挂载 router、store、i18n；路由按功能模块划分在 `src/router/index.js`，使用动态 `import()` 实现路由懒加载；页面组件位于 `src/views/`，通用 UI 组件集中在 `src/components/`；API 层通过 `src/apis/module/*.js` 按业务域拆分（admin、device、agent、knowledgeBase、voiceClone 等），统一由 `src/apis/api.js` 聚合导出，底层 HTTP 请求封装在 `src/apis/httpRequest.js`；状态管理使用 Vuex（`src/store/index.js`），国际化通过 vue-i18n 多语言文件（`src/i18n/*.js`）；构建配置基于 `vue.config.js`，生产环境启用 Terser 压缩、Gzip、Webpack Bundle Analyzer、Workbox Service Worker 以及可选 CDN 外部化；Docker 镜像采用双阶段构建（node:18-alpine 构建 → nginx:1.27-alpine 运行），启动脚本 `docker/start.sh` 通过环境变量 `UPSTREAM_API_ADDR` 注入后端代理地址并校验 DNS 解析。
