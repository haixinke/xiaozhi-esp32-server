# 04: 微信真机联调验收

**What to build:** 用一条测试外部游戏配置，在微信真机上验证智控台投放后的两个打开入口、正常返回路径与原生游戏回归，为启用外部游戏提供验收记录。

**Blocked by:** [03 从小纸条打开外部游戏](03-external-game-daily-note-launch.md)

**Status:** ready-for-agent

## 联调样例

- [瓶空一翻](https://game.eggbabe.com/games/bottle-flip/)
- [今日一签](https://game.eggbabe.com/games/daily-fortune/)

任选一个样例，同一条游戏配置勾选活动和小纸条，便于核对两个入口打开的是同一个游戏。另一个样例可用于更新链接后复测。两条链接共用 `game.eggbabe.com`，真机验收时确认该域名已配置为蛋宝宝的微信业务域名。

## 验收标准

- [ ] 使用带迁移的后端、新版小程序和可用于测试的 HTTPS H5。H5 域名已配置为蛋宝宝业务域名，真机验收开启正常域名校验。
- [ ] 在智控台为同一条外部游戏勾选活动和小纸条。准备可收到当日小纸条及触发连续奖励的测试账号，并保证测试纸条能够抽到该游戏。
- [ ] 分别从真机上的百宝箱活动和小纸条打开 H5，确认页面加载、查询参数和锚点到达预期位置，返回后可以继续使用小程序。打开小纸条的奖励按现有规则发放，外部游戏自身无星星和次数结算。
- [ ] 真机复查两个入口的内部游戏分流及一起画、听你说的原生页面。停用测试外部游戏，确认活动重新刷新及下一次有效纸条查询均不再分发该游戏。
- [ ] 在工单记录测试版本、两个入口的结果和未通过项。仅有自动化或开发者工具结果时，真机验收项保持待完成。正式启用外部游戏安排在后端迁移与新版小程序上线后。
