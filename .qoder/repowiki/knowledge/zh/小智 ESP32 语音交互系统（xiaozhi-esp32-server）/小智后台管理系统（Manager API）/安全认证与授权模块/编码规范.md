- 所有需要认证的接口通过 Shiro 过滤器链声明式控制，路径在 `ShiroConfig.filterChainDefinitionMap` 中集中配置，使用 `anon`、`oauth2`、`server` 等预定义过滤器名称。
- 自定义认证逻辑通过继承 `AuthenticatingFilter`（`Oauth2Filter`、`ServerSecretFilter`）并重写 `createToken`、`isAccessAllowed`、`onAccessDenied` 三个方法实现。
- Controller 统一使用 Lombok `@AllArgsConstructor` 注入服务依赖，并通过 `Result<T>` 包装响应体，异常通过 `RenException` + `ErrorCode` 抛出。
- 敏感操作（登录、注册、找回密码）的密码均经 `Sm2DecryptUtil.decryptAndValidateCaptcha` 解密后再与验证码校验，防止明文传输。
- 用户上下文通过 `SecurityUser` 静态工具类获取，避免在各处直接调用 `SecurityUtils.getSubject()`。
- 密码编码统一通过 `password/PasswordEncoder` 接口抽象，默认实现为自研 `BCryptPasswordEncoder`，由 `PasswordUtils` 对外暴露 `matches`/`encode` 方法。
