# 0001. 年龄区间独立于生日存储

- 状态：已接受
- 日期：2026-08-24

## 背景

蛋宝宝小程序需要按合规要求记录用户的年龄分段（年龄区间，见 CONTEXT.md）。`ai_wechat_user` 表已有 `birthday` 字段，资料页已支持编辑生日，理论上年龄段可由生日派生。

但年龄区间功能的合规文案明确承诺"不采集完整生日、身份证、监护人手机号"，且大量用户从未填写生日——由生日派生会导致该群体没有年龄段，两个入口语义重叠互相打架。

## 决策

在 `ai_wechat_user` 新增独立的 `age_range` 列（VARCHAR，存字典 `EGG_AGE_RANGE` 的 dict_value），与 `birthday` 完全解耦：

- 生日走资料页，年龄区间走专用年龄区间页，互不干扰；
- 年龄区间的取值、标签由字典驱动，运营可在智控台维护；
- 读写复用现有 `GET/PUT /wechat/profile` 链路，不单独开接口。

## 后果

- 同一用户的生日与年龄区间可能不一致（如填了生日但手动选了别的区间），系统不做一致性校验，以用户自选的年龄区间为准；
- 若未来需要精确年龄，需另行设计，不能假设 `age_range` 可由 `birthday` 重建；
- 字典 `EGG_AGE_RANGE` 的删除/修改会影响存量用户数据语义，运营侧需谨慎操作。
