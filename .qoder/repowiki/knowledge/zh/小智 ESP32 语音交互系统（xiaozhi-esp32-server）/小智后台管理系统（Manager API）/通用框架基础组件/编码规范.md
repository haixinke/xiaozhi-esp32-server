- 所有实体类继承 BaseEntity，并使用 @TableId/@TableField(fill=FieldFill.INSERT) 标注公共字段，由 FieldMetaObjectHandler 自动填充创建者、创建时间、更新者、更新时间及 dataOperation。
- Service 层遵循 BaseService<T> → BaseServiceImpl<M,T> → CrudService<T,D> → CrudServiceImpl<M,T,D> 的继承链，DTO 与 Entity 之间通过 ConvertUtils.sourceToTarget 转换。
- 错误码集中在 ErrorCode 接口中以 5 位数字定义（前两位模块码+后三位业务码），业务抛错统一使用 RenException(code, params)，由 RenExceptionHandler 转为 Result<T>。
- 分页查询通过 Constant.PAGE/LIMIT/ORDER_FIELD/ORDER 键名传递参数，BaseServiceImpl.getPage() 统一解析并生成 Page 对象。
- Redis 操作通过 RedisUtils 工具类进行，默认过期时间为 24 小时（DEFAULT_EXPIRE），需要设置过期时传入 NOT_EXPIRE 表示不过期。
- 数据权限通过 DataScope 注解 + DataFilterInterceptor 实现，在 Mapper 方法参数 Map 中放入 DataScope 对象即可自动追加 WHERE 条件。
