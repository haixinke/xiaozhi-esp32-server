- 每个 TTS 提供商在独立文件中定义一个名为 `TTSProvider` 的类并继承 `TTSProviderBase`，仅实现 `text_to_speak` 抽象方法与必要的初始化逻辑。
- 通过子类级 `TTS_PARAM_CONFIG` 列表声明可配置的百分比参数（键名、属性名、最小值、最大值、基准值、转换函数），由基类 `_apply_percentage_params` 统一注入。
- 日志记录统一使用 `TAG = __name__` 配合 `setup_logging()` 获取 logger，并通过 `logger.bind(tag=TAG)` 输出结构化日志。
- 音频输出统一经 `handle_opus` 写入 `tts_audio_queue`，由 `_audio_play_priority_thread` 消费并通过 `sendAudioMessage` 异步发送，避免阻塞事件循环。
- 文本预处理遵循固定流程：MarkdownCleaner 清理 → correct_words 正则替换 → 按标点分段 → 调用 `to_tts_stream` 或 `to_tts_single_stream`。
