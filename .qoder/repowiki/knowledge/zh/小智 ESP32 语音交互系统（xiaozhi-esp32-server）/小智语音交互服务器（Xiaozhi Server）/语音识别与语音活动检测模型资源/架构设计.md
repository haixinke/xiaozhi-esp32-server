本模块以两个独立子目录组织预训练模型资源：
- `SenseVoiceSmall/`：基于 FunASR 框架的多语言语音识别模型，通过 `configuration.json` 声明 framework=pytorch、task=auto-speech-recognition、model.type=funasr，并引用 `config.yaml`（定义 encoder=SenseVoiceEncoderSmall、tokenizer=SentencepiecesTokenizer、frontend=WavFrontend 等超参）和 `chn_jpn_yue_eng_ko_spectok.bpe.model` 分词器；`demo.py` 展示通过 `funasr.AutoModel` 加载本地模型目录进行推理。
- `snakers4_silero-vad/`：Silero VAD 的完整包结构，`src/silero_vad/` 为 Python 包，`__init__.py` 暴露 `load_silero_vad`、`get_speech_timestamps`、`VADIterator` 等 API；`model.py` 根据 onnx 参数选择加载 `.jit` 或 `.onnx` 模型文件（位于 `data/` 目录），并通过 `importlib_resources` 定位资源；`utils_vad.py` 实现 `OnnxWrapper`（基于 onnxruntime）、`Validator`、音频读写、VAD 时序分割等核心逻辑；`hubconf.py` 提供 torch.hub 入口，将 `silero_vad` 函数与 utils 元组一并返回。
依赖方向：两个子模型均只读静态资源，无相互依赖，由上层服务按需加载。
