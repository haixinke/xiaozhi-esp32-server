- 每个业务 API 模块独立成目录（如 agent、chat-history、device、voiceprint），内部按 `接口函数.ts` + `types.ts` + `index.ts` 三件套组织，对外仅暴露 index 聚合导出。
- Pinia store 模块按功能拆分单文件（config、lang、provider、speedPitch、user），并通过 `store/index.ts` 统一 re-export，所有 store 数据默认持久化到 `uni.setStorageSync/getStorageSync`。
- 页面路由通过 `src/pages/` 下的文件夹结构自动生成，tabbar 配置集中在 `src/layouts/fg-tabbar/tabbarList.ts`，并通过 `pages.config.ts` 的 `defineUniPages` 注入，避免手写 pages.json。
- 组件通过 easycom 自动注册（`wd-*` 映射 wot-design-uni、`z-paging*` 映射分页组件、`fg-*` 映射本地组件），无需手动 import 即可在模板中使用。
- HTTP 请求统一通过 alova 实例发起，通过 `config.meta.ignoreAuth`、`config.meta.domain`、`config.meta.toast`、`config.meta.isExposeError` 等元信息控制认证、域名覆盖、提示与错误暴露行为。
- 国际化文案通过 `src/i18n/index.ts` 的 `t(key, params)` 函数获取，语言包按 `语言代码.ts` 命名并导入到 messages 映射中，当前语言由 store/lang 模块驱动。
