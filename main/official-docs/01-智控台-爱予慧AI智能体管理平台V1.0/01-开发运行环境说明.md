# 爱予慧AI智能体管理平台 V1.0 — 开发运行环境说明

## 开发的硬件环境

MacBook Pro（Mac17,2），Apple M5 芯片，32GB 内存。

## 运行的硬件环境

- 客户端：普通 PC / Mac，4GB 内存以上，可运行现代浏览器；
- 服务端托管：Linux 服务器（4 核 CPU / 8GB 内存以上），用于托管静态资源与反向代理，支持 Docker 部署。

## 开发该软件的操作系统

macOS 26。

## 软件开发环境 / 开发工具

- Visual Studio Code（前端开发）；
- Node.js + npm（依赖管理与本地调试）；
- Vue CLI 5（工程构建）；
- Git（版本管理）。

## 该软件的运行平台 / 操作系统

浏览器端软件，运行于 Chrome、Edge、Safari 等现代浏览器，不依赖特定操作系统；服务端静态资源托管于 Linux 服务器（如 CentOS 7 / Ubuntu 20.04）。

## 软件运行支撑环境 / 支持软件

- 浏览器：Chrome / Edge / Safari 等现代浏览器；
- 静态资源托管：Nginx；
- 配套后端：爱予慧AI智能体管理服务后端（Java Spring Boot，端口 8002，上下文路径 /xiaozhi）。

## 编程语言

JavaScript（Vue.js 2 框架）、HTML、CSS。

## 源程序量

约 52000 行（取 manager-web 前端 Vue/JS 源代码实测约 5.2 万行，含注释）。

## 开发目的

为 AI 语音陪伴硬件产品线提供一体化运营管理控制台，使运营人员无需接触代码即可完成智能体配置、设备管理、NFC 资产管理、模型参数调整与用户运营，降低 AI 硬件产品的运营门槛与运维成本。

## 面向领域 / 行业

人工智能物联网（AIoT）、AI 语音陪伴智能硬件、情感陪伴软件运营支撑领域。

## 软件的主要功能

1. 智能体管理：AI 角色模板、智能体配置、声纹与音色管理、聊天记录与上下文管理；
2. AI 宠物养成运营：蛋宝宝宠物的孵化、领养、动作与场景故事引擎配置；
3. NFC 资产全生命周期管理：商品类型、生产批次、Scheme 任务、工厂 CSV 写卡与手动写卡、锁卡复验、触碰激活、审计日志；
4. 设备与用户管理：ESP32 设备绑定与激活、微信小程序用户、邀请码、订阅与支付；
5. 模型与参数管理：大模型/语音合成/语音识别供应商配置、系统参数与字典管理；
6. 用户反馈管理：用户诉求的提交、受理编号追溯与运营处理；
7. 系统管理：账号权限、服务端节点、OTA 固件升级管理。

## 软件的技术特点

- 基于 Vue.js 2 + Element UI 的前后端分离管理控制台架构；
- 基于 Provider 模式的 AI 供应商适配层，多服务商参数可视化配置；
- NFC 写卡批次状态机与触碰自验证机制；
- 故事引擎按时段驱动宠物叙事状态轮换；
- 细粒度数据字典驱动的运营可配化，无需发版即可调整业务参数。
