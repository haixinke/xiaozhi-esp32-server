## 软件功能与技术特点（填表参考文案）

> 以下为草稿，可按系统字数限制删减。

爱予慧AI智能体管理服务后端是一套面向 AI 语音陪伴硬件产品线的 Java Spring Boot 管理后台 RESTful 服务软件。系统以端口 8002、上下文路径 /xiaozhi 对外提供 RESTful API，为智控台 Web 端与移动管理端提供接口，同时作为 Python 语音核心服务的配置数据来源，完成设备注册绑定、智能体配置、OTA 固件升级、NFC 写卡与领取、声音克隆、知识库、支付订阅、故事引擎、系统管理等全业务管理，并实现智能体参数的运行时热下发。

主要功能模块：

1. 设备管理：设备注册、绑定/解绑智能体、OTA 固件升级、通讯录与权限；
2. 智能体管理：智能体配置 CRUD、配置快照回溯、声纹、MCP 接入点、模板、聊天历史；
3. 远程配置下发：智能体参数持久化，供 Python 服务端拉取热重载，无需重启即生效；
4. NFC 写卡与领取：产品类型、批次、资产、写卡任务、领取、Scheme、操作日志全生命周期管理；
5. 宠物与陪伴上下文：宠物档案、记忆、聊天、故事、陪伴上下文管理；
6. 声音克隆：声音样本上传、克隆任务提交、声音资源管理；
7. 知识库：知识库与知识文件管理，供检索增强；
8. 支付与订阅：订单、支付回调、订阅周期管理；
9. 故事引擎：宠物故事节点编排与上下文推进；
10. 系统管理：管理员、字典、参数、操作日志、服务端管理。

技术特点：基于 Spring Boot 分层架构（接入/控制/服务/持久化四层）；Apache Shiro 过滤器链 + 权限注解实现粗细两级鉴权；MyBatis-Plus 通用 CRUD 降低样板代码；Liquibase 版本化数据库迁移保证多环境一致；操作日志切面无埋点审计；幂等切面保护支付回调；作为配置中枢实现智能体参数运行时热下发；Knife4j 自动生成接口文档。

## 与其他软著的关系
