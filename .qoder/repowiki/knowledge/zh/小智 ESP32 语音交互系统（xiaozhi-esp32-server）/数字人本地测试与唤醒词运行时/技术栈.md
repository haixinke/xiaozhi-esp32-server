Python 标准库 `http.server` + `threading` 自建 WebSocket（无第三方 WS 框架）；前端使用原生 JavaScript ES Module 引入 Live2D Cubism SDK（`cubism4.min.js`、`live2dcubismcore.min.js`、`pixi.js`）；唤醒词检测基于 sherpa-onnx zipformer Wenetspeech 模型（`sherpa-onnx-kws-zipformer-wenetspeech-3.3M-*` 目录下的 encoder/decoder/joiner .onnx 文件）；音频编码使用 Opus（`opus-codec.js` + `libopus.js`）。
