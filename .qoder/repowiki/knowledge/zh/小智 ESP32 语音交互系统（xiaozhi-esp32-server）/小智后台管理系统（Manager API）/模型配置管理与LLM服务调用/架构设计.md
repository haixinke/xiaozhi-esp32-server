模块按标准分层组织：controller层暴露REST API（ModelController管理模型配置、ModelProviderController管理供应器），service层定义接口（ModelConfigService、ModelProviderService、LLMService），impl层实现具体逻辑，dao层通过MyBatis-Plus操作数据库，entity/dto用于数据载体。

model子包负责模型元数据持久化：ModelConfigEntity映射ai_model_config表（含JSON字段configJson存储各模型的具体参数如base_url、api_key、model_name等），ModelProviderEntity映射ai_model_provider表（记录供应器类型providerCode及动态fields）。llm子包独立封装LLM调用能力，LLMService为抽象接口，当前仅OpenAIStyleLLMServiceImpl一个实现，通过RestTemplate直接HTTP POST到/chat/completions端点。

依赖方向单向向下：controller → service → dao/entity；LLMService实现类反向依赖ModelConfigService以读取运行时模型配置，形成跨包耦合。权限控制统一使用Shiro的@RequiresPermissions注解，API文档通过Swagger v3注解标注。
