- 配置加载采用默认配置 + 用户覆盖的双层 YAML 结构，通过递归 `merge_configs` 深度合并，用户配置优先级更高。
- 异步 HTTP 客户端使用类单例模式，按 `asyncio.get_running_loop()` 的 id 为每个事件循环维护独立的 httpx.AsyncClient 实例。
- API 业务错误通过自定义异常（`DeviceNotFoundException`、`DeviceBindException`）向上抛出，而非返回错误码。
- 日志通过 loguru 的 `extra` 字段注入 `selected_module`，并使用 `formatter` 回调统一处理默认值与动态模块字符串。
- 所有对外暴露的异步函数均通过 `_execute_async_request` 统一封装重试逻辑，对网络超时、5xx 状态码等场景进行指数退避重试。
