该模块是纯资源目录，按功能划分为五个子目录：
- `db/changelog/`：基于 Liquibase 的增量式数据库迁移，由 `db.changelog-master.yaml` 统一编排，每个 SQL 文件对应一个 changeSet，id 采用 `yyyyMMddHHmm` 时间戳命名，禁止修改已提交变更。
- `mapper/`：MyBatis-Plus 的 XML 映射文件，按业务域（agent、correctword、device、knowledge、model、security、sys、voiceclone）组织，通过 `application.yml` 中 `mybatis-plus.mapper-locations: classpath*:/mapper/**/*.xml` 自动扫描。
- `i18n/`：Spring Messages 国际化资源，包含 messages 与 validation 两类属性文件，覆盖 zh_CN、zh_TW、en_US、de_DE、pt_BR、vi_VN 六种语言。
- `lua/`：Redis Lua 脚本（emptyAll.lua、getKeyOrCreate.lua），供业务层原子操作使用。
- 根级配置文件：`application.yml` 定义 Tomcat、Spring、MyBatis-Plus、Knife4j、阿里云 OSS、微信生态等核心配置；`application-dev.yml` / `application-prod.yml` 按 profile 覆盖；`logback-spring.xml` 通过 dev/test/prod 三个 springProfile 区分日志输出策略。
