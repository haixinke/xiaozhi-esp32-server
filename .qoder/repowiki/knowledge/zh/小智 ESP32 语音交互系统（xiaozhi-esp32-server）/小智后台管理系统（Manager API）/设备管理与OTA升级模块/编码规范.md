- 实体类统一使用 Lombok @Data + MyBatis-Plus @TableName/@TableId/@TableField(fill=...) 注解，并配合 Swagger @Schema 描述字段。
- Controller 方法统一返回 xiaozhi.common.utils.Result<T> 包装对象，并通过 @RequiresPermissions("sys:role:normal") 进行权限校验。
- 业务异常通过抛出 RenException + ErrorCode 常量表达，而非返回错误码字符串。
- 外部系统调用（MQTT Gateway）统一通过 MqttGatewayAuthorization.postJson 发起，携带基于日期的 Bearer Token 鉴权。
- 异步操作使用 @Async 注解（如 updateDeviceConnectionInfo），并通过 AopContext.currentProxy() 调用以保证事务生效。
- DTO 与 Entity/VO 之间通过 ConvertUtils.sourceToTarget 或 BeanUtils.copyProperties 进行属性拷贝，避免手动赋值。
