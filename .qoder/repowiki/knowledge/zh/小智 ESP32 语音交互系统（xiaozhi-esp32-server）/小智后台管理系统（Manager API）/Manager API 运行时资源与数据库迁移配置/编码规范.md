- 数据库迁移文件命名采用 `yyyyMMddHHmm.sql` 格式，changeSet id 与文件名保持一致，且每次变更只允许新增文件，禁止修改已有 changeSet。
- Mapper XML 按业务域划分子目录（agent、device、sys 等），文件名以实体名加 Dao/Mapper 后缀，如 `AgentDao.xml`、`SysUserDao.xml`。
- 国际化资源成对出现 messages 与 validation 两类属性文件，每种语言对应独立后缀（如 `_zh_CN`、`_en_US`），并通过 `spring.messages.basename` 统一注册。
- 配置项优先通过环境变量注入（`${VAR_NAME:default}` 形式），敏感参数如 OSS、微信密钥均不硬编码在配置文件中。
- 日志配置通过 logback 的 springProfile 区分 dev/test/prod，生产环境仅输出到控制台以便容器日志采集。
