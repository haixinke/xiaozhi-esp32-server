# 04: 题组编辑与删除（物理删除）

**What to build:** 运营可对题库做修改：题组编辑弹窗内一次修改组名与组内全部题目（题干、选项文本），整组提交，后端单事务内 diff——带 id 的题目更新（id 保持稳定）、无 id 的新增、缺失的物理删除。删除支持两个粒度：删除单道题、删除整个题组（含组内题目），均为物理删除不可恢复，前端均有二次确认且文案明示不可恢复。保存时沿用判重规则（组名大类内唯一、题干组内唯一）。

**Blocked by:** 02 (题组浏览)

**Status:** ready-for-agent

- [ ] `PUT /admin/listen/group/{id}` 整组保存（diff：更新保 id / 新增 / 物理删除），单事务，超管权限
- [ ] `DELETE /admin/listen/group/{id}` 整组物理删除（含组内题目）
- [ ] `DELETE /admin/listen/question/{id}` 单题物理删除
- [ ] 保存判重：组名大类内、题干组内唯一
- [ ] 前端：题组编辑弹窗（组名 + 5 题题干 + 各 5 选项）、删除二次确认（文案明示物理删除不可恢复）
- [ ] Service 层单测：diff 三种路径 / 物理删除级联 / 判重拒绝
- [ ] 前端 node:test 相应更新
