## 软件功能与技术特点（填表参考文案）

> 以下为草稿，可按系统字数限制删减。

爱予慧AI智能体管理平台是一套面向 AI 语音陪伴硬件与配套小程序的一体化运营管理软件。平台采用前后端分离架构：前端基于 Vue.js 2 + Element UI 构建 Web 管理控制台，后端基于 Java 21 + Spring Boot 3 提供 REST API，数据层使用 MySQL 兼容数据库与 Redis 缓存。

主要功能模块：

1. 智能体管理：AI 角色模板、智能体配置、声纹与音色管理、聊天记录与上下文管理；
2. AI 宠物养成运营：蛋宝宝宠物的孵化、领养、动作与场景故事引擎配置；
3. NFC 资产全生命周期管理：商品类型、生产批次、Scheme 任务、工厂 CSV 写卡与手动写卡、锁卡复验、触碰激活、审计日志；
4. 设备与用户管理：ESP32 设备绑定与激活、微信小程序用户、邀请码、订阅与支付；
5. 模型与参数管理：大模型/语音合成/语音识别供应商配置、系统参数与字典管理；
6. 用户反馈管理：用户诉求的提交、受理编号追溯与运营处理；
7. 系统管理：账号权限、服务端节点、OTA 固件升级管理。

技术特点：基于 Provider 模式的 AI 供应商适配层；NFC 写卡批次状态机与触碰自验证机制；故事引擎按时段驱动宠物叙事状态轮换；细粒度数据字典驱动的运营可配化。
