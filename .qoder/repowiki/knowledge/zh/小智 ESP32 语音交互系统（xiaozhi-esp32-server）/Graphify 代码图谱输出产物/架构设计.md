该目录是 graphifyy 工具的纯输出产物，不包含任何可执行代码，由三个核心文件组成：
- `GRAPH_REPORT.md`：人类可读的 Markdown 报告，包含语料规模、节点/边/社区统计（10850 节点、15502 边、2588 社区）、提取置信度（84% EXTRACTED / 16% INFERRED）以及按社区组织的导航链接。
- `cost.json`：记录本次分析的 token 消耗与成本。
- `manifest.json`：描述被扫描项目的结构元数据。
- `cache/stat-index.json`：增量缓存索引，以绝对路径为键存储每个文件的 size、mtime_ns、word_count 及多份哈希，用于跳过未变更文件的重复分析。
- `.graphify_transcripts.json`：转录警告日志，记录因缺少 faster-whisper 而无法转译的音频/视频文件。
依赖方向单向：graphifyy → 源码仓库 → 本目录产物，产物之间无相互依赖，仅作为下游消费的数据源。
