- 新增消息类型需定义 TextMessageType 枚举值、实现 TextMessageHandler 子类，并在 Registry._register_default_handlers 中注册。
- 插件模块统一暴露 create_instance(type, config[, extra]) 工厂函数，由 modules_initialize 根据 selected_module 配置选择具体实现。
- 所有处理器以独立文件组织，按功能命名（如 helloMessageHandler.py、abortMessageHandler.py），并通过 __pycache__ 缓存避免重复导入开销。
- 日志输出统一使用 setup_logging() 返回的 logger 并绑定 TAG=__name__，便于追踪来源。
