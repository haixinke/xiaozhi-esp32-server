- DTO内部类统一使用Lombok的`@Data`+`@Builder`+`@NoArgsConstructor`+`@AllArgsConstructor`组合，并通过`@Schema`描述OpenAPI元数据。
- 与RAGFlow交互的字段通过Jackson的`@JsonProperty`/`@JsonAlias`注解保持snake_case命名兼容。
- Controller方法统一返回`Result<T>`包装类型，参数校验使用`@Validated`配合Jakarta Validation注解。
- 权限校验在Controller层通过`SecurityUser.getUserId()`获取当前用户后与实体`creator`字段比对，不匹配则抛出`RenException(ErrorCode.NO_PERMISSION)`。
- RAGFlow HTTP调用统一经`RAGFlowClient`发起，异常通过`convertToRenException`转换为业务异常，避免分散的错误处理逻辑。
- 跨服务编排（如级联删除）抽取到独立的`KnowledgeManagerService`接口及其实现中，使用`@Transactional(rollbackFor = Exception.class)`保证事务一致性。
