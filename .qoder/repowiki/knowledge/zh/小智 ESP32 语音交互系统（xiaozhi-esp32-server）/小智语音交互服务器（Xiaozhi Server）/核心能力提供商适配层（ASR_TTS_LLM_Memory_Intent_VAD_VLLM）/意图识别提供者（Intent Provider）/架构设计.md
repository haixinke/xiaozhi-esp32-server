模块采用抽象基类 + 多实现的 Provider 模式：
- base.py 定义 IntentProviderBase 抽象基类，统一 detect_intent(conn, dialogue_history, text) -> str 异步接口，并通过 set_llm(llm) 注入 LLM 实例。
- 三个具体实现分别位于独立子包中，命名冲突通过包隔离解决：function_call/function_call.py 固定返回 continue_chat；nointent/nointent.py 同样固定返回 continue_chat；intent_llm/intent_llm.py 为完整实现，通过 LLM 动态解析用户输入，结合 conn.func_handler.get_functions() 和可选的 MCP 工具列表生成系统提示词，并使用 core.utils.cache.manager 按 (device_id, text) 的 MD5 缓存结果。
- 依赖方向单向向下：所有实现仅依赖 base.IntentProviderBase，不反向依赖；LLM 调用通过 asyncio.to_thread 避免阻塞事件循环，错误时回退到 continue_chat。
- 输出格式统一为 JSON 字符串 {"function_call": {"name": "...", "arguments": {...}}}, 支持 continue_chat、result_for_context 以及任意函数调用三类意图。
