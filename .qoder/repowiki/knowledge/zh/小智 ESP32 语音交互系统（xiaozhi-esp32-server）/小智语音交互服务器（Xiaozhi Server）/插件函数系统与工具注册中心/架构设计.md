模块采用「注册表 + 装饰器 + 自动导入」的分层架构：
- `register.py` 定义核心基础设施：`ToolType`（工具类型枚举，区分普通等待、系统控制、IoT控制等）、`Action`（动作结果枚举）、`ActionResponse`（统一返回结构）、`FunctionItem`（函数元数据容器）、`DeviceTypeRegistry`（IoT设备类型注册表），并通过 `register_function` 装饰器将函数写入全局 `all_function_registry`。
- `loadplugins.py` 使用 `importlib` + `pkgutil.iter_modules` 自动扫描 `functions/` 包下所有模块并动态导入，触发各模块顶层的装饰器完成注册。
- `functions/` 目录下每个文件是一个独立工具插件，遵循统一契约：定义 OpenAI 风格的 `function_desc` 字典，用 `@register_function(name, desc, type)` 装饰异步或同步函数，函数签名通常以 `conn: ConnectionHandler` 作为第一个参数。
- 依赖方向单向：插件 → register（注册）→ loadplugins（发现），插件之间通过 `hass_init.py` 等共享初始化逻辑耦合，不直接互相调用。
