# 03: NFC 领取无需预先绑定手机号

**What to build:** 未绑定手机号的用户真实触碰 NFC 后，可浏览预览、确认领取蛋宝宝并完成孵化体验；破壳成功且动画结束后进入统一的强制手机号绑定流程。领取资格、NFC 资产归属及锁卡复验规则继续生效。

**Blocked by:** 01 — 破壳后强制绑定手机号闭环。

**Status:** resolved

- [x] 未绑定手机号的有效微信账号触碰 NFC 后，可进入预览并按资产实际状态展示领取入口，不在预览或确认领取前要求手机号授权。
- [x] NFC 确认领取的前端及后端均移除手机号前置条件；服务端继续校验真实登录用户、领取功能开关、有效领取凭据、资产状态、归属及领养资格。
- [x] 预览失败、网络失败或确认领取失败时保留现有安全提示和重试能力，不将手机号授权作为恢复领取的必经步骤。
- [x] 保持同原型限领、邀请码与 NFC 渠道互斥、本人已领取直达宠物、他人已领取不可领取及并发防重复领取规则；重复原型拦截不消耗 NFC 资产。
- [x] 触碰自验证、锁后触碰复验、锁卡和入库规则继续有效，未绑定手机号的触碰同样可提供原有验证证据。
- [x] 未绑定账号领取后可完整体验既有孵化及破壳流程；破壳成功且动画结束后进入任务 01 的绑定闭环，拒绝或失败时保留破壳成果。
- [x] 本人触碰已领取且已破壳的宠物时，未绑定账号仍进入统一绑定流程；已绑定账号直接继续，多宠物领取和切换不重复要求绑定。
- [x] 先写失败测试再实现，验证未绑定账号从 NFC 触碰、预览、确认领取到孵化及破壳后绑定的完整路径，并覆盖本人/他人已领取、重复原型、无效凭据、关闭领取、并发确认、网络重试及锁卡复验回归。
- [x] 完成相关前后端回归及工程检查，变更逻辑的有效测试覆盖率至少 80%；日志和测试输出不暴露手机号、领取凭据、授权凭据或会话凭据。
- [x] 同步 NFC 领取与手机号绑定时机的现行说明，更新 ADR 0003 中确认领取保留手机号门禁的旧约定，仅替代手机号相关部分，保留原有 NFC 验证、锁卡和入库决策。

## Answer

已移除 NFC 领取前的前后端手机号要求，保留资产、资格、并发与锁卡复验规则；渠道替换后按最新活跃宠物恢复门槛，旧 ADR 已注明替代关系。

验证结果与限制统一记录在本功能 spec 的验证记录中。
