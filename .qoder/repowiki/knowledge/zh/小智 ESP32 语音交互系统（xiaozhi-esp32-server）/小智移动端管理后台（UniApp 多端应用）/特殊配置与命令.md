必须使用 pnpm（packageManager 锁定 10.10.0，preinstall 强制 only-allow pnpm）。常用命令：`pnpm dev`（H5 开发）、`pnpm dev:mp-weixin`（微信小程序）、`pnpm dev:app-android` / `dev:app-ios`（原生 App）、`pnpm build:h5` / `build:mp-weixin` / `build:app`（对应构建）；`pnpm type-check` 执行 vue-tsc 类型检查；`pnpm test:snapshot` 运行 agent 快照测试；`pnpm openapi-ts-request` 通过 openapi-ts 从后端 OpenAPI 生成前端请求代码。
