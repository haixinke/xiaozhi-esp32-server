模块由一个入口服务器类 `SimpleHttpServer`（`http_server.py`）和 `api/` 下的三个处理器组成：
- `base_handler.BaseHandler` 是所有业务 Handler 的基类，统一注入 `config`、日志器，并提供 `_add_cors_headers` 和 `handle_options` 以支持跨域预检。
- `ota_handler.OTAHandler` 实现 `/xiaozhi/ota/`（GET/POST/OPTIONS）和 `/xiaozhi/ota/download/{filename}` 路由，负责设备身份解析、MQTT/WebSocket 配置下发、`data/bin/*.bin` 固件缓存与版本比较、以及安全的二进制文件下载。
- `vision_handler.VisionHandler` 实现 `/mcp/vision/explain`（GET/POST/OPTIONS），通过 multipart/form-data 接收图片与问题，调用 `core.utils.vllm.create_instance` 动态实例化 VLLM 模块进行视觉问答。
- `SimpleHttpServer` 在 `start()` 中根据 `read_config_from_api` 决定是否挂载 OTA 路由，并始终挂载 Vision 路由；使用 `web.AppRunner` + `web.TCPSite` 启动 aiohttp 服务，监听 `server.http_port`。
- 依赖方向单向：`SimpleHttpServer` → `OTAHandler/VisionHandler` → `BaseHandler`，业务逻辑不反向依赖路由层。
