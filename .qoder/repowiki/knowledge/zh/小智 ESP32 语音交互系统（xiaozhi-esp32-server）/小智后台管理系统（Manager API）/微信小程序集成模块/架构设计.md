模块采用标准的 Controller-Service-Dao-Entity 分层结构：
- controller/WechatController 暴露 /wechat 路径下的 REST 接口，通过 @RequiresPermissions 和 SecurityUser.getUserId() 完成鉴权与当前用户上下文获取。
- service/WechatService 定义业务接口并继承 common 层的 BaseService<WechatUserEntity>；impl/WechatServiceImpl 基于 BaseServiceImpl 实现，使用 MyBatis-Plus 的 QueryWrapper/UpdateWrapper 操作 WechatUserDao。
- entity/WechatUserEntity 映射 ai_wechat_user 表，dto/vo 分别承载请求参数与响应视图（含脱敏逻辑）。
- util/ProfileValidator 集中校验昵称、性别、MBTI、城市等字段；service/WechatPhoneGate 作为独立 Gate 判断用户是否已绑定手机号。
- 依赖方向单向向下：Controller → Service → (Dao + 外部 OSS/Redis/微信 HTTP)；对外部系统调用集中在 WechatServiceImpl 的 httpPost/jscode2session/getAccessToken/getPhoneNumber 等方法中，便于单测桩替换。
