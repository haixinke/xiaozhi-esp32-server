- 每个 Page 和 Component 都采用 js/json/wxml/wxss 四件套文件组织，并在 json 中显式声明 usingComponents 引用。
- HTTP 请求统一通过 `utils/request.js` 的 get/post/put/del 方法发起，所有服务端响应走 `{code, msg, data}` 信封格式，401 时自动静默刷新 token。
- 本地持久化统一使用 `wx.setStorageSync`/`wx.getStorageSync`/`wx.removeStorageSync`，并以 `eggbaby_*` 前缀命名 key（如 `eggbaby_auth_token`、`eggbaby_mvp_pet_v1`）。
- 异步操作返回统一的 `{ ok, message?, ...payload }` 或 Promise 形式，错误信息优先取 `error.userMessage`，失败时通过 `wx.showToast` 提示用户。
- 组件通过 `properties` 声明外部传入参数，通过 `triggerEvent('back')` 等方式向上抛出事件，避免直接调用父级方法。
- 测试文件与源码同名并放在同目录下（如 `account.test.js`、`auth.test.js`、`pet-store.test.js`），便于与源码一一对应。
