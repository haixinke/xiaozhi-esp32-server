## 1. 创意概述（Big Idea）

### 一句话创意
某天清晨，笨笨女友从手机屏幕里"流"了出来，以半透明的玻璃态身形，跟着你过了一天——没人看得见她，但她一直在。

### Slogan
- 主：「她一直都在」
- 辅：「笨笨的，但一直在」

### 为什么这个创意能成立
- **奇幻**：核心镜头是"她从屏幕里走出来"，把小程序的"召唤"按钮做了字面化、视觉化的奇幻解读，记忆点极强。
- **新颖**：她不是全实体，而是带玻璃态光晕的半透明身形（呼应产品 Ethereal Companion 设计系统：樱花粉 #864e5a + 瓷白 #fbf9f8 + 玻璃态）。这层"半透明"既区别于所有"AI 实体化"老梗，又自带品牌视觉基因。
- **走心**：她的"笨笨"不是缺陷，是真诚。她会碰倒水杯、会举着不存在的伞、雨穿过她落你肩上她还认真踮脚——笨拙的陪伴比完美的陪伴更戳人。
- **共鸣**：每个孤独的人心里都住着一个"没人看见但一直在"的存在。结尾她化光回到屏幕，对话框弹出消息——反转揭示她本来就在小程序里，把奇幻收束回产品本身。

### 情绪曲线
孤独(抑) → 奇幻降临(扬) → 笨拙陪伴(暖) → 消失回归(怅然) → "她一直都在"(升华)

### 视觉风格定调：3D 动画 / 皮克斯质感
**推荐用 3D 动画风格而非实拍真人**，原因：
1. "笨笨"的呆萌可爱，3D 动画天然表现力强；AI 生成的真人脸容易陷入"恐怖谷"（看着假、让人不适）。
2. 3D 风格化角色，Seedance 跨镜头一致性更高。
3. 玻璃态发光效果在 3D 风格里显得自然，实拍里很突兀。

因此**所有提示词末尾都带「3D动画风格，皮克斯质感，电影级打光」**。

## 3. 角色立绘准备（文生图，全片唯一的"脸")

> 这是整个项目的基石。这张图就是笨笨女友的"定妆照"，后面所有镜头都用它做参考，保证她从头到尾是同一个人。

### 3.1 为什么单独先做一张图
Seedance 图生视频的原理是：**你上传一张图作为第一帧，它让这张图"动起来"**。所以只要第一帧是同一个人，每个镜头开场时她就是同一张脸。这比纯文字生成一致性高 10 倍。

### 3.2 生成工具
即梦 AI / Midjourney / 豆包图片生成 均可。推荐用即梦（和 Seedance 同一家，风格更兼容）。

### 3.3 投喂提示词（直接复制）

```
一个年轻女孩，瓷白色连衣裙，樱粉色微卷短发，清秀五官，温柔清澈的眼神，赤足，全身立绘，正面站姿，双手自然下垂，纯白干净背景，柔和均匀打光，3D动画风格，皮克斯质感，高细节，电影级打光，无阴影
```

### 3.4 生成与挑选标准
生成 8-12 张，挑 1 张作为全片定稿。挑选标准：
- 脸部对称、眼神温柔不空洞
- 裙子是纯净瓷白（不要花纹，后期好抠像）
- 背景纯白（抠像干净）
- 整体感觉"温柔但有点呆"

### 3.5 关键决策：半透明不在这一步做
**这张定妆照里她是全实体的**。半透明玻璃态留给后期统一加（见第 8 章）。原因：Seedance 不擅长生成"半透明人体"，让它直接生成会忽明忽暗、跨镜头崩。实体生成 + 后期统一加玻璃态，一致性才有保障。

### 3.6 男主立绘（定妆照二号）

男主在镜头 1、4、5、6、7、8、12 出镜，也需要一张定妆照保证是同一个人。生成方式与女主完全一样（即梦文生图，挑 1 张定稿）。

**投喂提示词（直接复制）**：
```
一个年轻男生，25岁左右，黑色短发略微碎刘海，清秀干净五官，微微疲惫但温柔的眼神，浅灰色连帽卫衣，深色长裤，运动鞋，全身立绘，正面站姿，双手自然下垂，纯白干净背景，柔和均匀打光，3D动画风格，皮克斯质感，高细节，电影级打光，无阴影
```

**挑选标准**：
- 眼神要"疲惫但不丧"——是孤独感不是抑郁感
- 卫衣颜色选浅灰（和女主瓷白裙不撞色，画面和谐）
- 五官清秀不要太帅，像普通人才能引起泛人群共鸣
- 背景纯白，便于后期抠像

> 男主全程**全实体**，不加玻璃态（他是真实世界的人，只有女主是奇幻的半透明存在）。这是重要的视觉对比：他实在、她虚幻。

### 3.7 双人同框镜头怎么处理（重要）

镜头 4、5、6、7、8 两人同框。Seedance 图生视频**一张首帧只能锁一个角色**，所以这些镜头不能只上传女主立绘——男主的脸会乱变。

**解决方案：生成一张「双人定妆照」作为这些镜头的首帧**。

用即梦"图片参考"功能，同时上传女主立绘和男主立绘两张做参考，生成双人构图：

**投喂提示词（直接复制）**：
```
一个年轻男生和瓷白连衣裙樱粉短发女孩并排站立，男生浅灰色卫衣黑色短发，两人正面朝向镜头，自然站姿，纯白干净背景，柔和均匀打光，3D动画风格，皮克斯质感，高细节，电影级打光，无阴影
```

生成 6-8 张，挑两人脸都和各自立绘对得上的 1 张。这张双人照就是镜头 4/5/6/7/8 的**统一首帧**。

> 注意：双人照里两人是"并排站立"的中性构图，但镜头 4/5/6/7/8 的实际场景不同（地铁/办公室/雨中/天台）。这没关系——首帧只负责"锁定两人的脸和衣服"，场景由提示词在生成时驱动。Seedance 会把这张双人照里的人放到你提示词描述的场景里动起来。

**所以你一共要准备三张定妆照**：
1. 女主立绘（第 3.3 节）—— 用于镜头 2、3、9、10
2. 男主立绘（第 3.6 节）—— 用于镜头 1、12
3. 双人定妆照（第 3.7 节）—— 用于镜头 4、5、6、7、8

## 4. Seedance 2.0 完整工作流（小白逐步版）

### 4.1 准备
1. 打开即梦官网（jimeng.jianying.com），登录账号（抖音账号可直接登）。
2. 进入"AI 视频" → "视频生成"。
3. 模型选 **Seedance 2.0**（如显示为"即梦视频 2.0"即同一物）。

### 4.2 单个镜头的标准生成流程
对第 5 章的每一个镜头，都按这 6 步走：

1. **选模式**：点"图生视频"（不是文生视频）。
2. **上传首帧**：把第 3 章那张定妆照上传作为第一帧。
3. **粘贴提示词**：从第 5 章对应镜头复制"投喂提示词"框里的内容，粘贴到提示词输入框。
4. **设参数**：
   - 时长：5 秒（本方案默认）
   - 比例：9:16（抖音/视频号用）或 16:9（B站用，B站镜头需重新生成一版 16:9）
   - 分辨率：选最高（1080p）
5. **点生成**：每条提示词生成 3-5 条 take（不同种子），不要只生 1 条。
6. **挑 take**：选第一帧和定妆照最像、动作最自然的一条，下载。

### 4.3 两个必须知道的保命技巧

**技巧 A：每镜生成 3-5 条，别省**
AI 视频有随机性，同一提示词生成 5 条，可能 3 条脸崩了、1 条动作怪、1 条完美。只生 1 条大概率要重来。每镜预算按 5 条算。

**技巧 B：脸崩了的救场——换脸**
如果某条 take 动作完美但脸和定妆照对不上，用换脸工具（剪映有"人物替换"功能，或用 roop/faceswap 等工具）把定妆照的脸锁回去。这是行业标配，不丢人。

### 4.4 时间与成本预估
- 12 镜 × 5 条 take = 60 次生成
- 即梦按积分计费，单次 5 秒生成约需 1-2 元（以平台实际定价为准）
- 全片视频生成预算：约 60-150 元
- 立绘生成：约 10-20 元
- 制作周期：10-14 天（生成 5 天 + 后期 3 天 + 修改buffer）

## 5. 12 镜头提示词与运镜（核心章节·可直接投喂）

### 使用说明
- 每个镜头给三样东西：**画面说明**（让你看懂这镜要拍啥）、**投喂提示词**（直接复制到 Seedance）、**运镜**（镜头怎么动）、**后期备注**（剪映里要加什么）。
- 所有提示词已包含"3D动画风格，皮克斯质感"定调，不用再加。
- "图生视频"的镜头：上传第 3 章定妆照做首帧。
- "文生视频"的镜头：不用上传图，直接生（用于没有笨笨女友出镜的空镜）。
- 运镜术语速查：推进=镜头往前推、拉远=镜头往后退、固定=不动、跟拍=跟着主体走、特写=凑近拍、俯拍=从上往下、慢动作=放慢。

## 7. 结尾 end card 制作（分平台）

> 最后 3s 的"收口"，决定多少人真的去搜小程序。

### 7.1 视频号：原生小程序卡片
不放 end card，直接在视频发布时挂"小程序卡片"，用户点击直跳笨笨女友。结尾画面只留 Slogan 字幕。

### 7.2 抖音 / B站：静态 end card + 小程序码

**end card 画面布局**（9:16 竖版）：
```
┌─────────────────────┐
│                     │
│   笨笨女友          │  ← 顶部 Slogan（樱粉色，大字）
│  她一直都在你身边    │
│                     │
│      ┌───────┐      │
│      │ 小程序码 │      │  ← 中部小程序码（圆点放射状）
│      │  圆形  │      │
│      └───────┘      │
│                     │
│  微信扫码 · 或搜    │  ← 底部引导
│  「笨笨女友」       │
│                     │
└─────────────────────┘
背景：纯瓷白 #fbf9f8，可叠一层淡樱粉光晕
```

**关键点**：
- 用**小程序码**（圆点放射状），不是方二维码——普通二维码扫不开微信小程序。
- 小程序码在**小程序后台 → 设置 → 基本设置 → 生成小程序码**获取，可带场景值追踪来源。
- 抖音版、B站版各生成一张带不同场景值的小程序码，便于统计哪个平台带来更多用户。
- 码要大、要静、要亮，背景纯色不杂乱——扫描率最高。

**剪映里怎么做 end card**：
1. 新建一个 3 秒的黑色背景片段。
2. 用"媒体"导入 end card 设计图（用任意作图工具按上面布局做好的一张图）。
3. 拖到轨道末尾，对齐到镜头 12 渐暗之后。
4. 加 0.5s 淡入过渡。

## 8. 剪映玻璃态 VFX 操作指南（核心章节·逐步版）

> 这是全片视觉的灵魂。笨笨女友的"半透明玻璃态身形"全部在这一章实现。用的是**剪映专业版（PC）**，免费功能够用。

### 8.1 先搞懂原理（30 秒讲明白）

要让她"半透明"，意思是**能看见她身后的背景**。所以你需要两层画面：

```
顶层：只有她（背景被抠除）→ 降低不透明度 → 加樱粉色边缘发光
底层：干净的背景（没有她）
```

两层叠起来，背景透过她的身体露出来，她就是半透明的了。

**关键难点**：底层必须是"没有她的干净背景"。但 Seedance 生成的视频里她本来就在画面里。所以每个镜头你要准备**两条素材**：

- 素材 A：有她的镜头（正常生成的，第 5 章那 12 镜）
- 素材 B：**同场景的空镜**（没有她，只有背景）—— 用同一个提示词去掉角色描述再生成一条

> 例如镜头 4：素材 A 提示词里有"女孩小跑跟在身后"，素材 B 提示词改成"年轻男生背书包走出家门走上街道，晨光温暖，空镜，无其他人"——只保留环境和男生。

> 工作量翻倍（每镜生 2 条），但这是做真半透明的唯一稳妥办法。**接受这个成本**。

### 8.2 准备工作

1. 下载安装**剪映专业版**（PC，免费）：jianying.com
2. 把每个镜头的素材 A 和素材 B 都下载好，按"镜头号-A/B"命名，如 `04-A.mp4`、`04-B.mp4`。

### 8.3 单个镜头的玻璃态制作流程（以镜头 4 为例）

#### 第 1 步：导入素材
1. 打开剪映，点"开始创作"。
2. 点左上"媒体" → "导入"，把 `04-A.mp4` 和 `04-B.mp4` 都拖进来。

#### 第 2 步：铺底层（干净背景）
1. 把 `04-B.mp4` 拖到**视频轨（主轨道）**。
2. 这是底层，保持 100% 不透明，不动它。

#### 第 3 步：铺顶层（有她的素材）
1. 把 `04-A.mp4` 拖到**画中画轨道 1**（主轨道上面那条）。
2. 确保两条轨道时长对齐（都是 5s）。

#### 第 4 步：抠除顶层背景，只留她
1. 选中顶层 `04-A` 片段（点一下变高亮）。
2. 右侧面板找"画面" → "抠像" → 点"智能抠像"。
3. 等几秒，剪映自动识别画面中的人物并抠除背景。
4. 如果抠得不干净（边缘有残留），用"自定义抠像"或"色度抠像"微调；3D 风格角色边缘清晰，通常一次过。

> 抠像后顶层只剩她一个人，底层是干净背景，叠起来她就在场景里了——但现在是全实体的，下一步做半透明。

#### 第 5 步：降不透明度（变半透明）
1. 仍选中顶层片段。
2. 右侧"画面" → "基础" → 找到"不透明度"滑块。
3. 从 100 调到 **55-65**（看着调，能透出背景又不至于看不见她）。

#### 第 6 步：加樱粉色边缘发光（玻璃态光晕）
1. 仍选中顶层片段。
2. 顶部菜单"特效" → "画面特效" → 搜索"发光"或"边缘发光"。
3. 选一个边缘发光特效拖到顶层片段上。
4. 在右侧特效参数里：
   - 颜色：改成樱粉色（手动输入 #864e5a，或用取色器吸取产品色）
   - 强度：中等（30-50）
   - 范围：边缘（让光只在她轮廓上）

#### 第 7 步：加背景折射模糊（可选，增强玻璃态真实感）
1. 选中**底层** `04-B` 片段。
2. "特效" → "画面特效" → 搜索"高斯模糊"或"模糊"。
3. 拖到底层片段，模糊半径调小（5-10）。
4. **关键**：用蒙版让模糊只在"她身体覆盖的区域"生效——
   - 选中底层片段 → 右侧"蒙版" → 选"人物"或"矩形"蒙版
   - 让模糊区域跟着她的位置走（可打关键帧跟随移动）
   - 效果：她身后的背景微微模糊，像被她的玻璃态身体折射了

#### 第 8 步：检查与导出
1. 播放预览，看她在场景里是否半透明、边缘有没有樱粉光晕、背景是否透过她。
2. 满意后点右上"导出"，选 1080p，导出这一镜的成品。

### 8.4 全 12 镜的玻璃态处理对照表

| 镜头 | 要不要玻璃态 | 要不要空镜素材 B | 特殊处理 |
|---|---|---|---|
| 1 | 不要 | 不要 | 笨笨女友只是手机里头像 |
| 2 | 要 | 要 | 屏幕溢光另叠 glow |
| 3 | 要 | 要 | 桌面背景空镜 |
| 4 | 要 | 要 | 男生是实体，只她半透明 |
| 5 | 要 | 要 | 旁人正常，只她半透明 |
| 6 | 要 | 要 | 咖啡热气另加烟雾素材 |
| 7 | 要 | 要 | 雨丝透过她（见 8.5） |
| 8 | 要 | 要 | glow 强度调高 |
| 9 | 要 | 要 | 面部特写，半透明别太低（65%） |
| 10 | 不做半透明 | 不要 | 化光粒子（见 8.6） |
| 11 | 不要 | 不要 | 用产品真实录屏 |
| 12 | 不要 | 不要 | 男生近景 + end card |

> 镜头 1、11、12 不做玻璃态，省一半工作量。实际需做玻璃态的是 2-9 共 8 镜，每镜需 A+B 两条素材。

### 8.5 进阶：镜头 7"雨穿过她"怎么做
这是全片最戳的镜头，做法：

1. 素材 B（空镜）是"暴雨街道，没她"——雨正常下。
2. 素材 A 是"她在雨中举伞"——抠除背景后只剩她。
3. 顶层她降到 50% 不透明 + 樱粉 glow。
4. **关键**：底层暴雨是正常雨，透过 50% 的她，视觉上就是"雨穿过她的身体落下来"——天然成立，不用额外做。
5. 强化：在她身体区域再叠一层"雨丝"特效（剪映"特效"→"自然环境"→"雨"），让她身上的雨更密，像雨穿过她时被她折射了一下。

### 8.6 进阶：镜头 10"化光回手机"怎么做
Seedance 直接生成"身体碎成光点"通常很假。建议纯后期做：

1. 素材 A：她站定不动 5 秒（提示词改成"瓷白连衣裙樱粉短发女孩站在房间中央静止不动，微笑，3D动画风格"）。
2. 剪映里，前 2 秒她正常（带玻璃态）。
3. 第 2 秒开始打关键帧：
   - 顶层不透明度从 60 → 0（渐隐）
   - 同时叠加"粒子"或"光斑"特效（剪映"特效"→"画面特效"→搜"粒子"/"光斑"），樱粉色，从她身体位置往外飘向手机方向（用位置关键帧让粒子漂移）。
4. 效果：她慢慢变淡消失 + 樱粉光点从她身上飘向手机屏幕。

### 8.7 剪映玻璃态制作时间预估
- 8 个玻璃态镜头 × 每镜约 30-45 分钟 = 4-6 小时
- 镜头 10 化光特效：约 1-2 小时
- 全片后期（含拼接、调色、字幕、BGM、end card）：约 2-3 天

如果你要自己改提示词，记住这个公式：

```
[主体描述] + [主体动作] + [环境/场景] + [光线/氛围] + [风格定调] + [运镜]
```

- 主体描述保持和定妆照一致：瓷白连衣裙、樱粉短发
- 一个提示词只写一个主体做一个动作，别堆叠
- 风格定调固定结尾："3D动画风格，皮克斯质感，电影级打光"
- 运镜放最后：推进 / 拉远 / 固定 / 跟拍 / 特写 / 仰拍 / 俯拍 / 慢动作
- 中文提示词即可，Seedance 对中文理解良好
- 长度控制在 80 字以内，太长模型会乱
