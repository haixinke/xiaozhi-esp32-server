- Controller 统一使用 @AllArgsConstructor + @RestController + @RequestMapping 组合，并通过 @RequiresPermissions("sys:role:superAdmin") 标注需要超级管理员权限的接口。
- Service 接口继承 BaseService<S>，实现类继承 BaseServiceImpl<S, T>，复用分页、CRUD 等通用能力，避免重复代码。
- DAO 层仅定义继承 BaseDao<T> 的 Mapper 接口，配合 @Mapper 注解，不使用 XML 或手写 SQL。
- Entity 使用 Lombok @Data/@EqualsAndHashCode(callSuper=false) + MyBatis-Plus @TableName/@TableField(fill=FieldFill.INSERT_UPDATE) 注解完成 ORM 映射。
- DTO 与 Entity/VO 之间通过 ConvertUtils.sourceToTarget 进行转换，保持入参与出参解耦。
- 所有写操作（save/update/delete/resetPassword/changeStatus 等）在 Service 实现中使用 @Transactional(rollbackFor = Exception.class) 声明事务。
