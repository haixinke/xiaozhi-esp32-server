模块采用标准的 Spring MVC 分层结构：`controller` 暴露 REST API（`CompanionController` 处理 CRUD 与聚合 setup，`CompanionContextController` 提供 `/config/companion-context` 实时上下文端点）；`service` 层通过 `CompanionService` 接口与 `CompanionServiceImpl` 实现核心业务，继承 `BaseServiceImpl<CompanionDao, CompanionEntity>` 复用 MyBatis-Plus 基础能力；`dao` 仅定义 `CompanionDao`；`entity` 使用 MyBatis-Plus 注解映射 `ai_companion` 表；`dto/vo` 分别承载入参与出参；`util` 存放纯函数工具（`IntimacyRule`、`CompanionMood`、`MenstrualCycleUtil`、`ReshapeVoucherRule` 等），无 Spring 依赖便于单测；`task` 通过 `CompanionTaskConfig` 启用 `@EnableScheduling`，由 `CompanionMoodRefreshTask` 每日零点批量刷新心情与亲密度。模块依赖外部子系统：`agent`（智能体提示词同步）、`device`（设备绑定与 WebSocket 信息）、`item`（重塑券扣减）、`security`（用户权限），依赖方向单向向外，不反向依赖本模块。
