# 01: 小纸条手工管理

**What to build:** 运营可从「运营管理」进入「小纸条管理」，分页浏览、按完整日期精确查询、新增、编辑和物理删除每日内容。后端保存完整日期、标题、正文和可选节气，拒绝手工重复日期；本票据同时打通数据库、管理 API、页面和测试，但不包含导入、应用端当日查询或已打开状态。

**Blocked by:** None (can start immediately)

**Status:** claimed

- [ ] 按已确认设计建立 `ai_daily_note`：雪花 BIGINT 主键；`note_date DATE NOT NULL`；`title VARCHAR(50) NOT NULL`；`content VARCHAR(200) NOT NULL`；`solar_term VARCHAR(50) NULL`；`creator`、`create_date`、`updater`、`update_date` 审计字段；`note_date` 唯一索引；无软删字段。
- [ ] Liquibase 只追加 changeSet，不修改已有 changeSet。
- [ ] 管理接口使用 `/admin/daily-note`，提供分页、按 ID 详情、新增、编辑、按 ID 物理删除，全部要求超级管理员权限。
- [ ] 新增和编辑去除三个文本字段首尾空白；标题、正文必填且分别最多 50、200 个 Unicode 字符；节气可空、任意文案且最多 50 个 Unicode 字符；正文内部换行保留。
- [ ] 日期为真实完整年月日，允许过去、今天和未来；新增或编辑目标日期与其他记录冲突时明确拒绝，编辑自身不算冲突。
- [ ] 列表默认按日期倒序，支持完整日期精确过滤，显示日期、标题、节气、正文摘要和更新时间。
- [ ] 智控台菜单、路由、页面与 API 接线完成；新增编辑共用表单，编辑展示完整正文。
- [ ] 删除确认显示日期、标题及物理删除不可恢复说明；不提供软删、恢复、上下架或审核。
- [ ] 先写失败测试再实现；Service 集成测试覆盖 CRUD、日期过滤与唯一冲突、空白和字符长度边界，HTTP 测试覆盖权限和统一错误结构。
- [ ] 保留项目现有前端 Node 测试及必要接线测试，Vue 模板检查和生产构建通过。
- [ ] 提供人工验证清单：菜单可见性、分页、日期查询、新增编辑校验、重复日期提示、删除确认；人工结果未执行前标记待验证。
- [ ] 遵循根术语表「小纸条」及 ADR 0006、0010 的删除决策背景，不实现本票据范围外能力。
