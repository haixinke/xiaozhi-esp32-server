模块采用标准的 Controller-Service-DAO-Entity 分层结构：
- controller 包暴露 REST 接口（PetController、ChatController、MemoryController、ProfileController、PetContextController），统一通过 `xiaozhi.common.utils.Result` 返回，权限校验使用 Shiro 的 `@RequiresPermissions("sys:role:normal")`。
- service 层定义接口并实现业务编排（PetServiceImpl 为核心，继承 BaseServiceImpl<PetDao, PetEntity>），依赖 LLMService、AgentService、DeviceDao、InviteService 等跨模块服务完成破壳时 Agent 创建、系统提示词注入、设备绑定等跨域操作。
- dao 层基于 MyBatis-Plus 的 Mapper 接口（PetDao、MemoryDao、UserProfileDao 等）；entity 层使用 `@TableName` + `@TableId(ASSIGN_UUID)` + `FieldFill` 自动填充审计字段。
- dto/vo 分离入参与出参，VO 由 Service.toVO 方法转换。
- config 包通过 `@ConfigurationProperties(prefix="seedream"|"pet.*")` 注入外部配置（Seedream 文生图、头像/场景/收藏卡属性）。
- util 包为纯函数工具类（MoodDecider、PetBirthCalculator、MbtiParser、PetNicknameGenerator、PetSystemPromptTemplate），无状态且可测试。
- event 包使用 Spring ApplicationEventPublisher 发布 CollectionCardGenerationEvent，配合 CollectionCardGenerationListener 异步处理收藏卡图片生成（当前被注释禁用）。
- constant 包集中枚举与常量（HatchActionType、TodayMood、MoodLinePool、MoodActingGuide）。
