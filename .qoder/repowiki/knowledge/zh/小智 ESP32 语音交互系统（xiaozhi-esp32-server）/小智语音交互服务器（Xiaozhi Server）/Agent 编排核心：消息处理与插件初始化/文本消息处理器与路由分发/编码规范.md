- 每个消息类型对应一个独立的处理器类，继承 `TextMessageHandler` 并实现 `message_type` 属性返回枚举值以及 `handle` 协程方法。
- 处理器内部不直接执行业务逻辑，而是 `await` 调用 `core.handle` 目录下同名业务处理函数（如 `handleHelloMessage`、`handleAbortMessage`）。
- 所有模块顶部定义 `TAG = __name__` 并通过 `conn.logger.bind(tag=TAG)` 进行结构化日志记录。
- 对连接对象 `ConnectionHandler` 的引用统一使用 `TYPE_CHECKING` 条件导入以避免循环依赖。
- 耗时或独立任务通过 `asyncio.create_task` 异步派发，避免阻塞主处理流程。
