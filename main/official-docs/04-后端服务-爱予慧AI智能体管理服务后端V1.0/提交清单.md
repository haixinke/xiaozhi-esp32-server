## 生成脚本（可重跑）

脚本位于 `main/official-docs/tools/05-后端服务/`：

- 源码 PDF：`python3 gen_source_manager_api.py`
  - 取材：manager-api 自研 Java 代码（AdminApplication → common 各子包 → modules 各业务模块）
  - 每页 60 行，line-height 3.95mm，共 696 类约 5.9 万行
- 设计说明书 PDF：`python3 gen_design_manager_api.py`
  - 21 章设计文档，基于真实 Spring Boot 架构与源码编制，含 3 张配图
  - 含模块清单（agent 89/pdc 112/sys 53/pet 52/storyengine 59/device 28 等）、实体字段、Shiro 配置、Liquibase changelog、接口规范
- 配图生成：`python3 gen_diagrams_manager_api.py`（graphviz dot → 3 张 PNG：分层架构/鉴权流程/配置下发时序）
- MIT 许可证明 PDF：复用上游 LICENSE（与 #3 语音服务同源）
