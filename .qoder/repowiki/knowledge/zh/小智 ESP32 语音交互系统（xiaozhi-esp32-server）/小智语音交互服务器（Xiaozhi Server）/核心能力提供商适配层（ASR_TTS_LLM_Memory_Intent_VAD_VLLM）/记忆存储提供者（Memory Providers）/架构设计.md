模块以 `base.py` 中的抽象基类 `MemoryProviderBase` 为核心接口，定义 `save_memory(msgs, session_id)`、`query_memory(query)` 两个异步方法以及 `init_memory(role_id, llm, **kwargs)` 初始化钩子；所有具体实现均继承该基类并在各自子目录中暴露同名 `MemoryProvider` 类，便于通过配置动态加载。

- 外部依赖层：`mem0ai/`、`volmem0/` 基于 `mem0.MemoryClient` 调用第三方 Mem0 服务；`powermem/` 基于 OceanBase PowerMem SDK，支持 sqlite/oceanbase/postgres 等多种向量存储与 qwen/openai 等 LLM/Embedding 提供商；`mem_local_short/` 使用本地 YAML 文件 + 内置 LLM 做短期记忆总结；`nomem/`、`mem_report_only/` 为无操作或仅上报的占位实现。
- 依赖方向单向向下：各实现仅依赖 `..base` 和通用工具（`core.utils.util.check_model_key`、`config.*`），不反向引用其他 provider。
- 运行时开关：每个 provider 在 `__init__` 中设置 `use_xxx` 标志（如 `use_mem0`、`use_powermem`），当配置缺失或初始化失败时优雅降级，避免阻塞主流程。
- 消息格式约定：保存前统一过滤 `system`/`tool` 角色，并尝试从 JSON 包装中提取 `content` 字段，保证与 ASR 情感/语言标签兼容。
