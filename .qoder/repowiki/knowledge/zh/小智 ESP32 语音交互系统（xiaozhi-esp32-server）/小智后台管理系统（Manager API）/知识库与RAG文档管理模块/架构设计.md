模块采用典型的Spring MVC分层结构：`controller`层通过`@RestController`暴露REST API（如`/datasets`），使用Shiro的`@RequiresPermissions`做权限校验；`service`层拆分为`KnowledgeBaseService`、`KnowledgeFilesService`两个领域服务以及`KnowledgeManagerService`编排服务，后者专门处理跨领域的级联删除以消除循环依赖；`dao`层基于MyBatis-Plus操作`ai_rag_dataset`等表；`entity`定义数据库实体，`dto`按功能域细分（dataset/document/KnowledgeFiles）并使用Jackson注解与RAGFlow协议对齐；`rag`子包通过抽象基类`KnowledgeBaseAdapter`定义统一接口，当前仅`RAGFlowAdapter`实现，由`KnowledgeBaseAdapterFactory`和`KnowledgeBaseConfig`注册Bean；`task`包包含定时任务`DocumentStatusSyncTask`用于同步RAGFlow端文档状态。依赖方向为 controller → service → (dao + rag.adapter)，adapter通过`RAGFlowClient`发起HTTP调用。
