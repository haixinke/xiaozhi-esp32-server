- Controller 统一使用 @RestController + @RequestMapping 根路径，方法通过 @Operation 描述 Swagger，参数校验使用 @Valid，返回统一封装 Result<T>。
- Service 接口定义业务契约，实现类放在 impl 子包并使用 @Service 注解，复杂事务方法通过 @Transactional(rollbackFor = Exception.class) 声明。
- Entity 使用 Lombok @Data + MyBatis-Plus @TableName/@TableId/@TableField(fill=...) 注解，字段通过 @Schema 描述用于 OpenAPI。
- DTO/VO 分离入参与出参，VO 通常提供静态 toVO(...) 方法从 Entity 转换，避免直接暴露实体。
- DAO 继承 BaseMapper<Entity>，复杂查询通过 QueryWrapper 构造条件，分页统一使用 Page 与 PageData 包装。
- 幂等与并发安全通过数据库唯一索引（如 uk_source_ref_sku）配合捕获 DuplicateKeyException 实现，而非应用层锁。
