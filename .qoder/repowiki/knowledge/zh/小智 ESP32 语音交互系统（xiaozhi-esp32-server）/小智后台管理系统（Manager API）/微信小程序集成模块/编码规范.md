- Controller 方法统一返回 Result<T> 包装，并通过 @Valid + JSR-303 注解进行入参校验，异常通过 RenException + ErrorCode 抛出。
- Service 层对写操作方法统一添加 @Transactional(rollbackFor = Exception.class)，保证事务一致性。
- 对外部 HTTP 调用（微信 jscode2session、stable_token、getuserphonenumber）封装为包级私有方法，超时固定 10s，错误统一转为 RenException。
- 敏感信息（手机号、openid）在日志输出前必须经 maskPhone 脱敏后再记录。
- 配置项通过 @Value 注入并使用 ${...:默认值} 语法提供回退值，避免启动时强制依赖环境变量。
