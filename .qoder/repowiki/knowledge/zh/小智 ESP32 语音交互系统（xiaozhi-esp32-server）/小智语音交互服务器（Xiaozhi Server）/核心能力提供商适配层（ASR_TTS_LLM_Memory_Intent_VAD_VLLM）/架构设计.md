本模块采用「Base抽象 + 多实现」的插件式架构：每个子目录（asr/tts/llm/memory/intent/vad/vllm/tools）均定义一个 `base.py` 抽象基类（如 ASRProviderBase、TTSProviderBase、LLMProviderBase、MemoryProviderBase、IntentProviderBase、VADProviderBase、VLLMProviderBase），所有具体厂商实现继承该基类并覆盖抽象方法。各 Provider 通过统一的接口契约被上层 core 模块以配置驱动的方式实例化与调用，实现热插拔切换。其中 asr/tts 基类还承担跨实现的通用流程编排（ASR 的 PCM→WAV 转换与声纹并行识别、TTS 的文本分段/Opus编码/流式队列与播放线程），tools 子模块则作为 LLM function_call 的统一执行入口，将服务端插件、MCP（设备端/服务端/外部端点）、IoT 等五类工具统一抽象为 ToolExecutor 并通过 ToolManager 调度。各 Provider 之间通过 ConnectionHandler 对象共享会话状态（session_id、sentence_id、sample_rate 等），并在需要时互相引用（如 Memory/Intent 通过 set_llm(llm) 注入 LLM 实例）。
