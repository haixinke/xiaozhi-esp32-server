本模块由 6 个独立的 Python 脚本组成，每个脚本对应一类被测组件（ASR、TTS、LLM、VLLM 视觉模型、流式 TTS、流式 ASR），均以 `async def main()` + `if __name__ == "__main__": asyncio.run(main())` 作为入口，可直接单独运行。
- 配置来源：统一通过 `config.settings.load_config()` 读取 YAML 配置，部分脚本（如 ASR）额外从 `data/*.config.yaml` 扫描合并 ASR 配置。
- 被测实例创建：均通过 `core.utils.*.create_instance`（或 `core.providers.asr.*` 直接导入 Provider）按配置的 `type` 字段动态构造被测对象，保持与业务代码一致的调用接口。
- 并发与超时：使用 `asyncio.gather` 并发执行多个测试任务；对阻塞 I/O 调用通过 `concurrent.futures.ThreadPoolExecutor` + `asyncio.wait_for(timeout=10s)` 实现超时保护；LLM 测试还对外层任务包裹 30s 超时。
- 结果聚合：每个脚本维护 `self.results`，在 `_print_results` 中用 `tabulate` 以表格形式输出，并按平均耗时/首 Token 时间升序排序，错误项排在末尾。
- 错误分类：统一识别 502/bad gateway、timeout、配置缺失等错误类型，记录 `error_type` 字段以便区分网络错误、超时、配置错误等。
- 依赖方向：仅单向依赖 `core.utils.*`、`config.settings` 和第三方库（aiohttp、websockets、tabulate、yaml），不反向依赖业务服务。
