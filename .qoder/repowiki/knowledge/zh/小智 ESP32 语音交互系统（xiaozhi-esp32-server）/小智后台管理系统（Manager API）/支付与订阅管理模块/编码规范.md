- 实体类统一使用 Lombok @Data + MyBatis-Plus 注解（@TableName、@TableId、@TableField(fill=FieldFill.INSERT/UPDATE)），并通过 io.swagger.v3.oas.annotations.media.Schema 描述字段。
- 服务层采用接口+impl 分离模式，controller 仅依赖接口，便于替换实现或 mock。
- 枚举常量以 final class + public static final String 形式集中定义（PayChannel、FeatureCode、OrderStatus、ProductType、SubscriptionStatus），不直接使用魔法字符串。
- 定时任务使用 @Component + @Slf4j + TransactionTemplate 包裹单条处理逻辑，批量限制通过 BATCH_LIMIT 常量控制，失败异常仅记录日志不中断批次。
- 对外返回统一封装 xiaozhi.common.utils.Result<T>，错误通过 RenException + ErrorCode 抛出。
