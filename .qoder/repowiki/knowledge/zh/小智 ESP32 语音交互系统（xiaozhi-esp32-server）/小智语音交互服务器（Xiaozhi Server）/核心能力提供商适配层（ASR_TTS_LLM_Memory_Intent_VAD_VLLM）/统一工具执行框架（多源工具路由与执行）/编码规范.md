- 每个工具类型都实现独立的`ToolExecutor`子类，统一暴露`execute(conn, tool_name, arguments)`、`get_tools()`、`has_tool(tool_name)`三个方法。
- 工具描述统一采用OpenAI函数调用JSON Schema格式（`{"type": "function", "function": {"name": ..., "description": ..., "parameters": {...}}}`）。
- 执行结果统一返回`ActionResponse`对象，通过`action`字段区分RESPONSE/ERROR/NOTFOUND/REQLLM等状态。
- 工具名称采用下划线分隔的命名约定，如IoT查询工具为`get_{device}_{property}`，控制工具为`{device}_{method}`。
- 错误处理统一捕获异常并包装为`ActionResponse(action=Action.ERROR, response=str(e))`，避免异常向上传播。
