# 04: 用户已打开状态

**What to build:** 用户调用 `POST /app/daily-note/opened` 后，该用户当天再次查询小纸条返回空，换设备仍生效，次日不继承。重复或并发上报幂等，运营覆盖、删除或同日重建内容不会重置已打开状态。

**Blocked by:** 02 JSON 导入与同日期覆盖；03 当日小纸条与随机游戏接口

**Status:** ready-for-agent

- [ ] 按已确认设计建立 `ai_daily_note_opened`：雪花 BIGINT 主键；`user_id BIGINT NOT NULL`；`note_date DATE NOT NULL`；`opened_at DATETIME NOT NULL`；`create_date DATETIME NULL`；联合唯一索引 `(user_id, note_date)`；不加 `note_date` 单列索引。
- [ ] 用户主键已核实为 BIGINT；不保存 `note_id`，不建外键，不级联删除打开记录。
- [ ] 标记接口无请求正文，用户 ID 来自 Token，日期由服务器按 `Asia/Shanghai` 决定；成功返回统一空数据结果。
- [ ] 当日小纸条不存在且用户没有已打开记录时，接口成功但不写记录；有当日小纸条时即使没有合格游戏也可写入。
- [ ] 重复调用成功且不改变首次打开时间；先查后插加唯一键冲突兜底，并发冲突视为成功且不产生重复记录。
- [ ] 当日查询先检查当日内容及当前用户该日期是否已打开，再选择游戏；已打开直接返回 `code=0, data=null`，不单独返回游戏。
- [ ] 状态按用户和完整日期隔离：不同用户互不影响，换设备仍生效，次日不继承。
- [ ] JSON 同日覆盖、物理删除和同日重建均不清除或重置已打开记录；内容被删除期间查询为空，重建后原用户仍为空，新用户可查看。
- [ ] 已打开记录永久保留，本期不提供后台查看、撤销、重置、恢复、统计或历史清理。
- [ ] 先写失败测试再实现；Service 集成测试覆盖首次写入、重复与并发幂等、无内容空操作、无游戏可写入、跨用户与跨日隔离、覆盖/删除/重建及随机游戏完整交互。
- [ ] MockMvc HTTP 测试覆盖标记路由、Token 用户传递及成功响应；运行相关后端测试和全量 Maven 测试。
- [ ] 不修改蛋宝宝小程序，不宣称真实客户端已验证；完成后更新代码知识图谱。
