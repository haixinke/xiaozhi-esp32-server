- Controller 统一使用 `@RestController` + `@RequestMapping` 定义路径，并通过 `@RequiresPermissions("sys:role:..." )` 标注角色权限，所有返回值包裹在 `Result<T>` 中。
- Service 接口继承 `BaseService<Entity>`，CRUD 方法命名遵循 save/update/delete/getById/page 等约定，业务方法以动词开头（uploadVoice、cloneAudio、getTimbreNameById）。
- Entity 使用 MyBatis-Plus 注解映射表结构，主键采用 `@TableId(type = IdType.ASSIGN_UUID)` 或字符串 id，创建/更新时间通过 `@TableField(fill = FieldFill.INSERT|UPDATE)` 自动填充。
- DTO/VO 与 Entity 分离，请求参数 DTO 通过 `ValidatorUtils.validateEntity(dto)` 进行校验后再传入 Service 层。
- 异常处理统一抛出 `RenException` 并使用 `ErrorCode` 枚举编码，Controller 层 catch 后转为 `Result.error(...)` 返回。
