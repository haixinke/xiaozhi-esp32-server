# 爱予慧AI语音交互服务系统 V1.0 — 开发运行环境说明

## 开发的硬件环境

MacBook Pro（Mac17,2），Apple M5 芯片，32GB 内存。

## 运行的硬件环境

Linux 服务器（如 CentOS 7 / Ubuntu 20.04），4 核 CPU / 8GB 内存以上，支持 Docker 部署；客户端为 ESP32 系列智能硬件终端（通过 WebSocket 接入）。

## 开发该软件的操作系统

macOS 26。

## 软件开发环境 / 开发工具

- PyCharm（Python 开发）；
- Python 3.10 解释器与虚拟环境；
- Git（版本管理）。

## 该软件的运行平台 / 操作系统

Linux 服务器操作系统（如 CentOS 7 / Ubuntu 20.04），支持 Docker 容器化部署。

## 软件运行支撑环境 / 支持软件

- Python 3.10 运行时（asyncio 异步框架）；
- 依赖中间件：Redis（缓存）、OceanBase / MySQL 兼容数据库（向量与图谱存储）；
- 外部 AI 服务：ASR / TTS / LLM 各服务商云端 API；
- 配套管理端：爱予慧AI智能体管理服务后端（运行时配置来源）。

## 编程语言

Python 3.10。

## 源程序量

约 33000 行（取 xiaozhi-server Python 源代码实测约 3.3 万行，含注释）。

## 开发目的

为 ESP32 智能语音陪伴硬件提供实时语音 AI 交互后端服务，完成从语音识别、意图理解、大模型推理到语音合成的全链路语音对话能力，并通过多服务商适配与远程热配置降低 AI 服务运营成本，保障语音交互的实时性、安全性与个性化。

## 面向领域 / 行业

人工智能物联网（AIoT）、AI 语音交互、智能语音陪伴硬件行业的服务端软件领域。

## 软件的主要功能

1. 实时语音对话：WebSocket 承载双向音频流，完成 VAD→ASR→意图→LLM→TTS 全链路交互，流式处理首字延迟秒级；
2. 多 Provider 适配：ASR（14 种实现）、TTS（20 种）、LLM（11 种）、VAD、意图、记忆六大能力均以工厂模式按配置实例化，支持数十家服务商热切换；
3. 工具与函数调用：统一工具处理器调度 IoT 控制、MCP 工具、服务端插件四类来源，15 个内置函数插件自动发现注册；
4. OTA 固件升级：HTTP 端点下发设备固件元数据与二进制包，支持 MD5 校验与 Token 鉴权；
5. 视觉分析：HTTP 端点接收图像，调用多模态大模型完成理解与描述；
6. 记忆与画像：基于 PowerMem 与 OceanBase 向量库/图谱存储用户长期记忆与画像特征，跨会话个性化；
7. 内容安全：输出门控机制对大模型输出在送入语音合成前进行安全校验与阻断；
8. 远程配置：对接智控台 API，运行时拉取配置覆盖本地，无需重启即生效；
9. AEC 全双工：声学回声消除使设备播放语音时仍可被用户打断；
10. 声纹识别：说话人识别联动记忆，支持同设备多用户独立记忆与画像。

## 软件的技术特点

- 基于 Provider 工厂模式的多服务商适配矩阵，AI 能力按配置热切换；
- 流式流水线编排（VAD→ASR→意图→LLM→TTS）实现秒级首字延迟；
- 输出门控内容安全机制，按句子粒度对大模型输出精准阻断；
- 三层配置递归合并与智控台远程热更新，无需重启生效；
- PowerMem 记忆与知识图谱实现跨会话个性化；
- AEC 声学回声消除支持全双工对话；
- GC 管理器避免实时语音链路出现垃圾回收停顿。
