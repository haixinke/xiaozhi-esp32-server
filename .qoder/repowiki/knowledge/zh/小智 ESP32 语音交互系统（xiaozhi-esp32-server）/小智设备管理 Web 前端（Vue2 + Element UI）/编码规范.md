- API 模块按业务域拆分为 `src/apis/module/<domain>.js`，每个文件暴露一个对象包含该领域的所有接口方法，最终由 `src/apis/api.js` 统一聚合导出。
- 路由定义统一使用函数式 `component: () => import(...)` 实现按需懒加载，并在 meta 中通过 `requiresAuth` 标记需要登录保护的页面。
- 组件命名采用 PascalCase 且以功能语义命名（如 AddDeviceDialog.vue、DeviceItem.vue），公共 UI 组件放在 `src/components/`，页面级视图放在 `src/views/`。
- 静态资源按用途分目录组织在 `src/assets/` 下（如 device-avatars、header、home、login、model、setting 等），与对应视图模块一一对应。
- 国际化文案按语言拆分为独立文件（`src/i18n/*.js`），Element UI 的 locale 通过 `locale.i18n` 桥接到 vue-i18n 的 `t` 函数。
- 环境变量通过 `.env.development` 和 `.env.production` 区分，构建时由 dotenv 加载，API 基础地址通过 `process.env.VUE_APP_API_BASE_URL` 读取。
