本模块是 core/utils 下的共享工具层，按职责拆分为若干独立文件与一个 cache 子包：
- 插件动态加载：memory.py、llm.py、intent.py、vad.py、asr.py、tts.py、vllm.py 均通过 `create_instance(class_name, ...)` 模式，基于配置中的 `selected_module` 和 `type` 字段，使用 `importlib.import_module` 从 `core.providers.<module>.<class_name>` 路径动态导入并实例化具体实现。
- 统一初始化入口：modules_initialize.py 的 `initialize_modules()` 根据传入的 init_* 开关与 config 中的 selected_module/type，调用各 provider 的 create_instance 组装 modules 字典，并支持 ASR 声纹识别的动态启用（`initialize_voiceprint`）。
- 全局缓存：cache/ 子包提供线程安全的 `GlobalCacheManager`（manager.py），配合 CacheStrategy（TTL/LRU/FIXED_SIZE/TTL_LRU）、CacheEntry、CacheConfig（config.py）与 CacheType 枚举（strategies.py）实现多命名空间、带过期与淘汰策略的内存缓存；模块内通过 `from core.utils.cache.manager import cache_manager` 单例访问。
- 提示词与上下文：prompt_manager.py 的 PromptManager 基于 Jinja2 模板渲染系统提示词，结合 ContextDataProvider（context_provider.py）通过 httpx 拉取配置的 context_providers 数据，并复用 cache_manager 缓存设备提示词、位置、天气等。
- 音频与编解码：util.py 集中 audio_to_data、pcm_to_data_stream、opus_datas_to_wav_bytes 等函数，依赖 pydub、opuslib_next、numpy；audioRateController.py、opus_encoder_utils.py、p3.py 分别处理采样率控制、Opus 编码器封装与 P3 格式。
- 其他辅助：auth.py、dialogue.py、gc_manager.py、output_counter.py、current_time.py、voiceprint_provider.py、wakeup_word.py、textUtils.py 提供鉴权、对话状态、GC 管理、输出计数、时间、声纹、唤醒词、文本处理等能力。
依赖方向：utils 层被上层 agent_orchestration 消费，自身仅依赖 config.logger、外部库（httpx、pydub、opuslib_next、jinja2）以及 core.providers.* 插件目录，不反向依赖业务逻辑。
