# 蛋宝宝小程序 MVP v1.0 · GPT

这是依据 `docs/蛋宝宝小程序MVP_PRD.md` 生成的微信原生小程序前端 MVP，可直接将本文件夹导入微信开发者工具。

## 已完成的核心闭环

微信授权进入 → 输入激活码 → 绑定唯一蛋宝宝 → 轻触 / 长按互动 → 完成孵化修炼手册 → 到达预设破壳日 → 生成唯一收藏卡 → 查看档案、每日状态与文字对话。

本版严格遵循最新 PRD：孵化期只展示蛋形，不展示背景场景，也不提供场景选择或切换入口。

## 目录

```text
project.config.json          微信开发者工具项目配置
```

## 本地预览

1. 打开微信开发者工具，导入 `蛋宝宝小程序_MVP_v1.0_20260710_GPT` 文件夹，而不是单独导入 `miniprogram/`。
2. 未配置正式 AppID 时可保留 `touristappid` 进行界面预览。
3. 勾选隐私政策后点击“微信授权并进入”。如果拒绝授权，页面会停留在进入页。
4. 使用下面任一演示激活码：
   - `DEMO-RABBIT`：获得玉兔，默认 7 天后破壳。
   - `DEMO-KOI`：获得锦鲤，默认 7 天后破壳。
   - `HATCH-NOW`：立即进入待破壳状态，用于检查收藏卡、档案和对话闭环。
   - `INVALID`、`USED`、`FULL`、`PAUSED`：分别检查四类异常提示。
5. 如需回到未添加蛋状态，在“我的 → 账号 → 退出登录”中清除本地数据。

## 当前实现边界

- MVP 数据由 `miniprogram/utils/pet-store.js` 使用微信本地存储模拟，方便无后端预览完整交互。
- 正式上线前需要把登录、激活码校验、唯一编号、每日状态、对话、分享图小程序码和数据统计接到服务端。
- 小程序内没有购买、支付、订单、退款、多宠物、排行榜、交易或语音功能。
- 收藏卡“保存图片”使用微信 Canvas 与相册能力；开发者工具里建议同时用真机验证授权流程。

## 校验

在项目根目录运行：

```bash
node scripts/verify-project.js
```

校验会检查页面四件套、JSON、组件引用、工程根目录设置，以及最新 PRD 禁止的孵化场景页面是否仍被编译。
