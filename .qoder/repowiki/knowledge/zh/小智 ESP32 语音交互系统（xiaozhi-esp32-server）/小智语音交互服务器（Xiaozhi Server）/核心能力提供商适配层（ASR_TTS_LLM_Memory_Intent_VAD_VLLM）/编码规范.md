- 每个 Provider 子模块均以 base.py 定义 ABC 抽象基类，具体实现通过继承并覆盖 @abstractmethod 方法接入系统
- 所有 Provider 基类统一使用 config.logger.setup_logging() 初始化 logger，并以 TAG = __name__ 作为日志标签
- 支持流式的 Provider（ASR/TTS/LLM）均采用 queue.Queue + 独立 daemon 线程的模式进行消息消费与处理
- Provider 间依赖通过 set_llm(llm) 或构造函数参数注入，而非直接 import 耦合
- 音频数据处理统一遵循 PCM→WAV→Opus 的转换链路，临时文件通过 tempfile 生成并按 delete_audio_file 配置决定是否清理
