# 头像资源说明

## avatar-default.png

请在 `images/` 目录下添加一个名为 `avatar-default.png` 的图片文件，作为 AI 伴侣的默认头像。

**建议规格：**
- 尺寸：160x160px（@2x）或更高
- 格式：PNG（支持透明）或 JPG
- 风格：温柔、治愈系的女性头像
- 建议：柔和的樱花粉色背景，或暖色调的日常生活场景

**设计理念：**
完美女友产品需要营造温暖亲密的视觉体验。头像应该：
- 表情温柔、眼神友善
- 色调温暖，避免冷色调
- 可以略带微笑或平静的表情
- 符合 Ethereal Companion 设计系统

## 临时方案

在添加真实头像之前，可以使用以下 CSS 渐变作为临时占位：

```css
.avatar-image {
  background: linear-gradient(135deg, #ffb7c5 0%, #864e5a 100%);
}
```
