# 02: 小程序首页信封入口与纸条弹层

**What to build:** 蛋宝宝小程序破壳后首页接入小纸条。左下角圆形按钮位二态切换：当日查询返回有效小纸条时显示信封图标（右上角红点，出现时纸飞机飞入动画约 1 秒 + 信封抵达动效 + 播放抵达音效），否则显示现有聊天 icon。点击信封弹出纸条弹层（标题、正文、节气、关联游戏区块、关闭按钮），弹出即调打开接口：成功则弹层内展示 "+N"（N 取响应 amount）、刷新左上角星星罐余额、当日入口回聊天 icon；失败 Toast 提示且信封红点保留可重试。游戏区块展示图标/说明/可赚星星数，点击 Toast "敬请期待"。

**Blocked by:** 01-opened-api-return-reward（弹层 "+N" 依赖打开接口返回金额）。

**Status:** open

## Acceptance Criteria

- [ ] 信封图标（png/webp）与抵达音效 mp3 从 UI 静态设计项目拷入小程序 assets，沿用项目本地资源引用惯例。
- [ ] 新增小纸条 API 封装（当日查询、标记打开），复用 request 封装与 Bearer 认证，401 静默重登由现有机制覆盖。
- [ ] 当日查询挂载在首页 `onShow` → 宠物列表成功且存在破壳宠物时，与星星余额加载并列；查询失败/返回空静默回退聊天 icon。
- [ ] 信封显示条件与聊天入口一致（仅"在家"大场景）；孵化中、未领养、无破壳宠物不出现信封。
- [ ] 抵达动画与音效对照 UI 静态设计稿实现：纸飞机 keyframes 动画、信封抵达态、InnerAudio 播放（音量 0.25、遵守静音开关、页面卸载释放资源）。
- [ ] 弹层仅含：标题、正文（保留换行）、节气（有才显示）、游戏区块（图标/说明/赚取星星数）、关闭按钮；不实现静态稿的记忆收集、互动反馈等其余功能。
- [ ] 点击信封先弹层再调打开接口；成功展示 "+N"（amount>0 时）并重拉星星余额；当日后续 `onShow` 不再显示信封（当日查询返回空）。
- [ ] 打开接口失败 Toast 提示，信封与红点保留，可重试；重复打开不会产生第二次 "+N"（后端幂等）。
- [ ] 游戏区块点击 Toast "敬请期待"，不做任何跳转。
- [ ] 新增 API 封装单测（node 直跑，mock request）；`home.test.js` 补：出信封/回 icon 的状态迁移、打开成功刷新余额、失败保留红点。
- [ ] `node --check` 全部改动文件通过；`scripts/verify-project.js` 通过；样式遵循 DESIGN.md。
