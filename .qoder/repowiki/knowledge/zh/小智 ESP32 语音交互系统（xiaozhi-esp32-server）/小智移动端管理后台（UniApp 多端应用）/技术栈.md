Vue 3.4 + TypeScript 5.7 + Vite 5.2；跨端框架为 uni-app 3.0（支持 H5、微信小程序、支付宝/百度/抖音/快手/Lark/QQ/小红书小程序、iOS/Android App、Harmony、QuickApp）；HTTP 客户端使用 alova 3 + @alova/adapter-uniapp；状态管理 Pinia 2 + persistedstate；UI 组件库 wot-design-uni 1.9；样式方案 UnoCSS 65 + SCSS；构建优化依赖 rollup-plugin-visualizer、@uni-ku/bundle-optimizer；测试使用 Node 原生 test runner 运行 .mjs 快照测试。
