以 `AdminApplication` 为启动入口，采用单 Jar 包部署的单体架构：所有业务模块均位于 `xiaozhi.modules.*` 包下，按 controller/dao/dto/entity/service/mapper 分层组织；横切能力集中在 `xiaozhi.common` 包（BaseEntity、BaseService/CrudService、Redis、异常、校验、XSS、分页、Result 等），被各模块共同复用。数据层统一通过 MyBatis-Plus + Druid 连接 MySQL，Liquibase 脚本存放在 `resources/db/changelog/` 并按时间戳命名驱动数据库演进。安全认证由 Apache Shiro（jakarta 版）集中配置，OAuth2 Token、短信验证码、BCrypt 密码与服务器密钥鉴权在 `modules/security` 中实现，其他模块通过 `@DataFilter`、`@LogOperation` 等注解接入权限与审计。跨模块依赖通过 service 接口调用或共享 common 工具类解决，避免循环依赖（如 knowledge 模块通过编排服务化解）。
