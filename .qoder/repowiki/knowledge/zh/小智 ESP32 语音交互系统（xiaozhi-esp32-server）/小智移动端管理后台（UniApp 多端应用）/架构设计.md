项目采用 uni-app 3.x 多端框架，以 Vite 为构建工具，通过 `@dcloudio/vite-plugin-uni` 及一系列 `@uni-helper/*` 插件（pages、layouts、manifest、platform）实现页面路由自动注册、布局注入、平台条件编译与 manifest 生成。

- 入口与初始化：`src/main.ts` 通过 `createSSRApp` 创建 Vue 应用，挂载 Pinia 状态管理、Vue Query 数据请求缓存、自定义路由拦截器以及 i18n 国际化。
- 网络层：`src/http/request/alova.ts` 基于 alova + @alova/adapter-uniapp 封装统一 HTTP 客户端，内置 Bearer Token 认证、401 自动跳转登录、混合内容检测、动态 baseURL 与语言头设置；各业务 API 按领域分目录（agent、chat-history、device、voiceprint、auth），每个目录包含 `*.ts` 接口定义与 `types.ts` 类型文件。
- 状态管理：`src/store/index.ts` 使用 Pinia + `pinia-plugin-persistedstate` 持久化到 `uni.getStorageSync/setStorageSync`，按功能拆分为 config、lang、provider、speedPitch、user 等模块。
- 路由与页面：`src/pages/` 下按业务域划分页面（agent、chat-history、device、device-config、login、register、settings、voiceprint 等），`src/pages-sub/demo/` 作为分包示例；路由由 `pages.config.ts` 通过 `defineUniPages` 配置 tabbar 与 easycom 自动扫描组件。
- 布局系统：`src/layouts/` 提供 default.vue、tabbar.vue 以及可切换策略的 `fg-tabbar` 组件（原生/自定义带缓存/无缓存/无 tabbar 四种模式），tabbar 列表集中定义在 `tabbarList.ts`。
- 国际化：`src/i18n/` 维护 zh_CN/en/zh_TW/de/vi/pt_BR 六套语言包，通过 `initI18n()` 和 `changeLanguage()` 配合 store 中的 lang 模块实现运行时切换。
- 构建与优化：`vite.config.ts` 集成 UnoCSS、unplugin-auto-import、rollup-plugin-visualizer、bundle-optimizer 等插件，支持 H5 生产环境打包分析与开发代理转发；`.env` 目录区分 development/production/test 环境变量。
- 工程规范：husky + lint-staged + commitlint 保证提交质量，ESLint 9 配合 `@antfu/eslint-config` 与 `@uni-helper/eslint-config`，TypeScript 严格类型检查通过 `vue-tsc --noEmit`。
