app.py 作为单进程异步主程序，按固定顺序完成：加载 YAML 配置（支持本地合并 + 远程 API 拉取）→ 初始化日志 → 启动全局 GC 管理器 → 并行创建 WebSocketServer 与 SimpleHttpServer 两个 asyncio 任务 → 阻塞等待 SIGINT/SIGTERM 后统一取消并清理资源。
- 连接面：WebSocketServer 负责设备鉴权（HMAC-SHA256 Token）、音频流收发与会话生命周期；SimpleHttpServer 暴露 /xiaozhi/ota/ 与 /mcp/vision/explain 两个 HTTP 端点。
- 编排面：core/handle 下的文本消息注册表将协议消息路由到具体处理器，并通过 core/utils/modules_initialize.py 动态装配 providers 下的 ASR/TTS/LLM/Memory/Intent/VAD/VLLM 多厂商实现。
- 插件面：plugins_func 提供可插拔函数库，由 register.py 装饰器自动发现加载，供 Intent/Tool 调用。
- 资源面：models_and_resources 预置 SenseVoiceSmall 与 Silero VAD 模型权重，config/assets 管理提示词与音效文件。
- 测试面：performance_tester 目录提供独立脚本对 ASR/TTS/LLM/VLLM 进行并发延迟基准测试。
所有子模块通过 config.settings 共享同一份配置对象，通过 core.utils.* 工具模块（llm/tts/asr/memory/intent/vad 等）解耦调用方与提供商实现。
