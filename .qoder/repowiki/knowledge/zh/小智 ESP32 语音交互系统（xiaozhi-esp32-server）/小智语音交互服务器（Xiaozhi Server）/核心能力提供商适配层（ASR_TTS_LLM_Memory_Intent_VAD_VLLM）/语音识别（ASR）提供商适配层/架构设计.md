模块以 `base.py` 中的 `ASRProviderBase` 抽象基类为核心，所有具体ASR实现（aliyun、openai、baidu、tencent、doubao、qwen3_asr_flash、fun_local、fun_server、sherpa_onnx_local、vosk、xunfei_stream、aliyun_stream、aliyunbl_stream、doubao_stream）均继承该类并实现 `speech_to_text` 方法。基类负责：
- 音频帧接收与VAD触发逻辑（`receive_audio`、`handle_voice_stop`）
- PCM→WAV转换、临时文件创建与清理（`_pcm_to_wav`、`build_temp_file`、`save_audio_to_file`）
- 与声纹识别并行执行（`asyncio.gather`）
- 结果统一封装并通过 `startToChat` 和 `enqueue_asr_report` 上报
- 通过 `InterfaceType`（STREAM/NON_STREAM/LOCAL）区分接口模式
- `dto/dto.py` 定义 `InterfaceType` 枚举；`utils.py` 提供 FunASR 标签解析工具 `lang_tag_filter`
依赖方向单向向下：各 provider → base → dto/utils → 上层 handle 模块，provider 之间互不依赖。
