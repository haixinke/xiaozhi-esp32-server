测试代码按生产包结构镜像组织：`xiaozhi.common.*` 下的工具/服务基类测试与 `xiaozhi.modules.<domain>/*` 下对应 service/impl、controller、util、dto、typehandler 等子目录一一对应，便于定位被测单元。所有测试均为纯单元测试，不启动 Spring 容器，通过 Mockito（含 `@ExtendWith(MockitoExtension.class)`、`@Mock`、`mockStatic`）隔离外部依赖；仅 `application.yml` 提供 Redis/Lettuce 基础配置供需要 RedisUtils 的测试使用。测试资源集中在 `src/test/resources/application.yml`，通过 Mock 静态方法（如 `SecurityUser`、`MessageUtils`、`SqlHelper`）和反射注入（如 `SpringContextUtils.applicationContext`、`quickHatchCode` 字段）绕过 Spring 初始化。
