开发环境：`npm run serve` 启动 devServer（端口 8001，代理 `/xiaozhi` 到 127.0.0.1:8002）；生产构建：`npm run build` 生成 dist 目录；包分析：`npm run analyze` 开启 webpack-bundle-analyzer；单元测试：`npm run test:unit` 和 `npm run test:snapshot` 使用 Node --test 运行 `.mjs` 测试文件；国际化检查：`npm run check:i18n` 执行 `scripts/check-i18n.js`；Docker 构建直接在本目录执行 `docker build`，运行时需设置 `UPSTREAM_API_ADDR` 环境变量指向后端服务。
